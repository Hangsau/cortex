拿起杯子時，肩肘把手送到位置，手腕建立底座，最後還要靠手指形成穩定的接觸。本章從這一步接著讀：拇指如何轉向其他手指，肌腱如何帶動多個關節，以及感覺如何協助調整力量。

先看骨與關節，再追肌腱和肌肉的合作，最後用抓握與臨床算例把它們連起來。理解的重點，是同一個末端動作背後，有哪些關節需要活動、哪些位置需要穩住。

## 先用指列，把掌骨與指骨接成一條鏈 {#terminology}

一條指列（ray）包括一根掌骨和相連的指骨。由橈側到尺側依序是拇指、食指、中指、環指與小指；這個分法讓我們從手掌基底一路追到指尖，而不只看露在掌外的部分。

掌骨與腕骨相接形成腕掌關節（CMC），掌骨與近節指骨相接形成掌指關節（MCP）。食指到小指各有近側指間關節（PIP）與遠側指間關節（DIP）；拇指只有兩節指骨，所以只有一個指間關節（IP）。

掌側皺褶讓皮膚在活動時摺疊，也有助於維持抓握接觸。但指根的皮膚皺褶位在 MCP 關節線較遠端，不能直接把每一道褶紋當成深層關節的位置。

## 掌骨與指骨 {#metacarpal-phalanges}

第一掌骨最短而粗，第二掌骨通常最長，其餘三塊由橈側至尺側逐漸變短。每塊掌骨有基底、骨幹、頸與頭；掌骨頭形成握拳時背側可見的指節，頸部是常見骨折位置。

近節與中節指骨有凹形基底、骨幹及凸形頭，遠節指骨末端的粗隆承接指腹軟組織。指骨掌側略呈縱向凹面，為肌肉與肌腱留下空間，也讓屈曲時的接觸形狀不同於背側。

拇指骨列位於不同平面。拇指掌骨相對其他掌骨近乎內旋九十度，讓敏感的掌側朝向手的中線；第一掌骨也位於更掌側，因此能掃過掌面與各指接觸。
{{< reading-source from="273" to="275" >}}

## 手的三道骨弓 {#hand-arches}

放鬆的手掌有自然凹面，由兩道橫弓與一道縱弓共同支撐。近側橫弓由遠側腕骨形成，較固定，配合橫腕韌帶圍成腕隧道；頭狀骨是其中央楔石，並由腕間接觸與強韌韌帶加固。

遠側橫弓通過 MCP 關節，兩側掌骨可向內折，使掌面包住球形物。第二、第三掌骨與其 MCP 構成穩定中央，第一、第四、第五掌骨則提供可動邊界。縱弓沿第二、第三指列延伸，近端由較穩的 CMC 固定，遠端在指屈伸時活動。

三道弓以第二、第三掌骨這條剛性繫梁相連。任何一弓因疾病失效，都可能削弱其餘結構；嚴重類風濕性關節炎破壞 MCP 時，掌面凹度與抓握穩定便會一起下降。

可對讀[Nordin 的掌弓與接觸形狀]({{< relref "/library/basic-biomechanics/ch14/index.md" >}}#hand-arches)，從另一冊的負荷觀點接著理解。

## 中央 CMC 柱與周邊活動 {#cmc-central}

第二、第三 CMC 的關節面互鎖，配合強韌背側與掌側腕掌韌帶，只允許很少活動，形成手的中央柱。這個穩定基底也承接橈側腕伸肌、橈側腕屈肌及拇收肌等重要肌肉。

第四、第五 CMC 則是尺側可動邊界。其掌骨基底與鉤骨相接，能屈曲並向中指方向內旋，使尺側掌緣向中央折疊，增加掌面凹度與抓握包覆。

屍體最大被動活動研究中，第四 CMC 屈伸約二十度、內旋約二十七度；當第四關節固定時，第五 CMC 屈伸約二十八度、內旋約二十二度。第四也自由時，第五屈伸平均可達四十四度；這些條件不可混為同一活動範圍。
{{< reading-source from="277" to="278" >}}

## CMC 關節的被動支持 {#cmc-ligaments}

第二至第五 CMC 都有關節囊、背側與掌側腕掌韌帶，以及掌骨間韌帶。中央關節靠互鎖骨面和韌帶固定，尺側關節則讓活動與穩定取得平衡；不規則骨面不宜硬套標準滾動滑動模型。

拇指 CMC 囊較鬆，以容納大而圓的活動弧，再由數條嵌入囊內的韌帶與肌肉張力加固。文獻對命名韌帶數目與功能有差異；本章以五條主要韌帶說明方向，並提醒名稱不等於唯一的功能分類。

橈側副韌帶與後斜韌帶較厚，拇指對掌、外展或屈曲時會變緊，也含較多感覺受器，可能參與本體感覺與保護。拇指 CMC 退化可伴隨軟骨磨損、囊韌帶鬆弛、疼痛與不穩，機制需放回個別關節負荷理解。
{{< reading-source from="278" to="279" >}}

## 手指動作與拇指方向 {#hand-motion}

手指屈曲、伸展在矢狀面，外展、內收在額狀面；中指是命名外展與內收的參考，向橈側或尺側的偏移也可用橈偏、尺偏描述。這些名稱假定肘伸直、前臂完全旋後、腕中立。

拇指屈曲是掌側表面在額狀面跨過掌面，伸展回到解剖位置；外展是近矢狀面向前離開掌面，內收回到手的平面。對掌（opposition）是拇指跨掌面接觸任一指尖，復位則由完整對掌返回解剖位置。

拇指方向詞不能直接套用手指。其指甲面朝外側、掌側朝內側、橈側朝前，這些相對方向是理解後續掌骨旋轉與對掌路徑的必要基準。
{{< reading-source from="276" to="277" >}}

## 拇指鞍狀骨面 {#thumb-saddle}

拇指 CMC 是典型鞍狀關節：大多角骨（trapezium）在掌背方向凹、內外側方向凸；第一掌骨則有互補的凸與凹。這種雙向曲率允許兩個主要自由度，也讓骨面在不同平面承受不同的滾動與滑動。

CMC 外展與內收大致在矢狀面，屈曲與伸展大致在額狀面；每一平面的轉軸通過凸面骨。外展時掌骨凸面向掌側滾、向背側滑，約四十五度前方位置可打開虎口，以包住大物體。

拇指屈曲時掌骨向內側、朝第三指旋轉，伸展時向外側旋轉；這個軸向旋轉不能獨立執行，所以不是第三個自由度。原書以從完全伸展到屈過掌面約 45°–50° 描述活動弧。

在屈伸方向，移動的是掌骨的凹面：屈曲時向尺側滾、也向尺側滑；伸展時兩者一起轉向橈側。這與外展時「凸面滾、滑反向」不同。先辨認正在看的平面，才能選對骨面規則。
{{< reading-source from="279" to="281" >}}

## 對掌的兩階段路徑 {#thumb}

完整對掌先以第一階段外展，再以第二階段屈曲並向內旋，讓拇指基底沿大多角骨表面朝尺側移動。後斜韌帶張力與拇對掌肌收縮共同引導掌骨進入骨面溝槽，使末端路徑既可動又穩定。

完整對掌包含約四十五至六十度的拇指內旋；主要來自 CMC，也有 MCP 與 IP 的附帶動作，大多角骨相對舟骨及小多角骨亦可能稍微內旋。第四、第五 CMC 的屈曲與旋轉所形成的杯狀動作，讓拇指更容易碰到環指與小指。

對掌末端被視為 CMC 密合位，因韌帶與肌肉共同增加關節吻合並限制附屬活動。這個末端穩定由肌肉、韌帶與骨面共同形成；回到原位時，則結合內收、伸展與外旋，讓拇指離開跨掌的位置。
{{< reading-source from="281" to="283" >}}

## 拇指基底的穩定，也伴隨內部壓縮力 {#thumb-load}

對掌時，肌肉與韌帶把活動的基底穩定下來，同時也會對關節面產生壓縮與剪力。原書引述強力側捏時，拇指 CMC 的壓縮力可達末端接觸力約 12 倍；這是特定分析中的內部力與指端力比較，不能當成所有捏取的固定倍率。

原書將反覆施加的關節力視為基底退化的可能參與因素之一，也同時討論受傷、遺傳、關節面配合與韌帶鬆弛。負荷機制因此有助於理解問題，卻不能把退化歸因於單一動作或單一數字。

當基底疼痛或不穩，原本可用來定位拇指的活動也可能變得難以控制。這說明拇指功能要一起看活動、穩定與接觸負荷，而不只追求能移動多大角度。

{{< reading-source from="282" to="283" >}}

## MCP 的囊、韌帶與掌側板 {#mcp-support}

手指 MCP 由凸的掌骨頭與淺凹的近節指骨基底形成卵圓關節，主動屈伸與外展內收各占一個平面。每個 MCP 囊內有橈、尺側副韌帶與掌側板，掌側板是厚而緻密的纖維軟骨樣結構，主要限制過度伸展。

每條副韌帶分為較厚的主束（cord）與較薄扇形的附屬束（accessory）。主束斜向掌側，屈曲時因掌骨頭的凸輪形狀而變緊；附屬束連到掌側板邊緣，屈伸全程長度較近似等長，提供較持續但較低的支持。

掌側板之間由三條深橫掌骨韌帶相連，鬆弛地整合第二至第五掌骨。這套組織把掌骨頭、近節指骨與屈肌腱滑車組成穩定座，也把各指的負荷連成掌弓系統。
{{< reading-source from="283" to="286" >}}

## MCP 活動與抓握適形 {#mcp-kinematics}

MCP 屈伸與外展內收之外，近伸直時還能被動牽開、壓縮、前後與側向平移及軸向旋轉。環指與小指的被動軸向旋轉最大，平均約三十至四十度，能使手指貼合圓形或不規則物體。

屈曲角度由食指約 90°，逐漸增加到小指約 110°–115°；MCP 可被動超伸約三十至四十五度，外展與內收約各二十度。這些是研究中的活動量，會受姿勢、被動或主動測試影響。

充分屈曲被視為 MCP 的密合位：許多周邊韌帶較繃緊，附屬活動較少。原書另指出許多抓握、捏取或用鑰匙的任務採約 60°–70° 屈曲；任務角度與密合位的定義需要分開。伸展時主束鬆弛，掌側板拉長，關節間隙可出現較多被動遊隙。
{{< reading-source from="284" to="286" >}}

## MCP 固定的條件限制 {#mcp-immobilization}

固定在縮短位置的關節周圍結締組織可能適應性變短，日後更抗拒拉長；固定在拉長位置則較可能保留原有剛度。原書以第四、第五掌骨頸骨折後固定三至四週、MCP 約七十度屈曲為例，說明保留副韌帶主束長度的理由。

這是特定情境的力學示例，不能轉成所有傷病的一致固定處方。若是背側囊重建或全關節置換，癒合中的組織可能需要 MCP 接近零度伸直，以減少背側張力，顯示固定角度必須依修復組織與手術條件決定。

MCP 完全屈曲時外展內收也會因副韌帶張力與掌骨頭掌側較平區域而受限。評估活動時，需分清主動範圍、被動遊隙、骨面阻擋與軟組織張力。
{{< reading-source from="286" to="287" >}}

## 拇指 MCP 與 IP {#thumb-distal-joints}

拇指 MCP 由第一掌骨頭與近節指骨基底組成，基本骨面與手指 MCP 相似，但活動顯著較小。實用上主要是一個在額狀面屈伸的自由度；由完全伸展主動屈曲約六十度，外展與內收多屬受限的附帶活動。

拇指 IP 同樣主要屈伸，屈曲約七十度、被動超伸約二十度。拇短屈肌與拇長屈肌共同屈 MCP，拇長屈肌是 IP 屈肌；骨面、掌側板與伸肌腱膜共同決定末端指腹能否穩定施力。

因此對掌不是 CMC 獨立完成的動作。CMC 提供主要跨掌路徑，MCP 與 IP 用較小的附帶旋轉和屈伸調整指腹方向，讓拇指能以指尖、指腹或側緣接觸物體。

## 指間關節的骨性導引 {#ip-joints}

PIP 由近節指骨頭與中節指骨基底構成，骨面像木工的舌槽接合：兩個髁與中央溝對上中節指骨的凹面與中央脊。這種骨性形狀限制軸向旋轉，使主要活動集中在屈曲與伸展。

PIP 與 DIP 都有關節囊、副韌帶及掌側板；PIP 掌側板近側增厚形成制動韌帶（check-rein ligaments），協助限制過伸，DIP 則沒有同樣明顯的制動韌帶結構。屈曲時背側囊被拉長，形成導引與穩定張力。

PIP 屈曲約一百至一百二十度，DIP 約七十至九十度；越尺側的手指通常屈曲較多。PIP 過伸很少，DIP 可超伸至約三十度；拇指 IP 主動屈曲約七十度、被動超伸約二十度。

## 神經分工與精細感覺 {#hand-sensation}

手的精細動作依賴肌肉、皮膚、肌腱、囊與韌帶的感覺受器。手內在肌每一運動神經軸突可能只支配約一百條肌纖維；相比之下，腓腸肌內側頭的單一軸突可支配約二千條，因此手內在肌能較細緻地分級力量。

橈神經主要支配手指外在伸肌，並負責腕背與拇指 CMC 背側區感覺；正中神經支配多數外在屈肌、原書所討論的魚際肌與橈側兩條蚓狀肌，並供應掌側橈側三個半指的感覺。尺神經支配指深屈肌尺側半、骨間肌、尺側兩蚓狀肌與小魚際肌。

原書另以 C6–C8 神經根整理關節感覺分布。神經根、周邊神經與皮膚感覺區是不同層次的地圖，不能只靠某一指的位置就完成神經定位。正常感覺會讓人只施加完成任務所需的力量；感覺缺失時，過大的接觸力可能反覆傷害皮膚與軟組織。
{{< reading-source from="289" to="290" >}}

## 感覺缺失與任務安全 {#sensory-protection}

正常感覺有助於把接觸力調到足以完成任務的程度。若正中、尺或橈神經的感覺支受到影響，使用者可能無法察覺過大的壓力、摩擦或熱刺激，手的保護能力便會下降。

原書以周邊神經病變、脊髓損傷與未控制糖尿病說明這種風險，也提到麻風病造成的無感指端可能因反覆過大接觸力而受損。這些是病例與機制的連結，不是對任何手部症狀的診斷。

因此抓握分析不能只問「肌肉有沒有力」。物體重量、接觸面、皮膚感覺、關節位置與反覆次數都會改變實際負荷；同一肌肉力量在不同感覺條件下，可能導致完全不同的任務結果。
{{< reading-source from="289" to="290" >}}

## 手部功能位置 {#position-of-function}

中樞神經損傷、腦中風或高位四肢癱瘓可造成長期麻痺、廢用或異常肌張力。原書以功能位置描述一種保留手部潛力的姿勢：腕伸約二十至三十度並稍尺偏，手指 MCP 屈約三十五至四十五度，PIP 與 DIP 屈約十五至三十度，拇指 CMC 外展約三十五至四十五度。

這些角度是圖示病例的姿勢參考，原書也明確說會依個人病況變化。其力學目的，是讓屈肌維持較合適長度、手掌保留部分凹度，並避免某些關節周邊組織在長期無力時縮短。

功能位置不能取代病因、關節活動與感覺評估。它與腱固定作用相連：腕的角度改變會以被動張力影響手指，即使手指本身的主動肌力有限，也可能保留部分抓握策略。
{{< reading-source from="289" to="290" >}}

## 外在屈肌與滑液鞘 {#tendon-path}

外在屈肌包括指淺屈肌（flexor digitorum superficialis, FDS）、指深屈肌（FDP）與拇長屈肌（FPL）。FDS 肌腱在近節指骨分叉，讓更深的 FDP 穿過；FDS 的兩股附著到中節指骨，FDP 則繼續到遠節指骨。FDS 主要屈 PIP，FDP 是 DIP 的唯一屈肌，兩者也會屈曲所跨過的其他關節。

FPL 是拇指 IP 的唯一屈肌，也對拇指 MCP 與 CMC 產生屈曲力矩。三組外在屈肌常一起收縮以形成強握，並可協助第一、第四、第五 CMC 的包覆動作；單一肌腱能否獨立控制，會受肌腱間肌束連結與手指差異影響。

腕隧道遠端有尺側與橈側滑液鞘，分別包覆多數屈肌腱與 FPL。手指纖維鞘形成骨纖維隧道，內含滑車與滑液鞘，供養、潤滑並減少屈肌腱彼此摩擦；發炎或沾黏會限制滑動。

## 屈肌滑車的幾何作用 {#pulley-system}

每指有 A1 至 A5 五個環形滑車，A2 與 A4 附著於近節與中節指骨骨幹，A1、A3、A5 靠近關節並附著掌側板；C1 至 C3 是較薄的交叉滑車。拇指則有環形與斜向滑車供 FPL 通過。

滑車、掌腱膜與皮膚把肌腱維持在靠近轉軸的位置，避免收縮時向掌側遠離關節而弓弦化。弓弦化會增加力臂與力矩優勢，卻減少每單位肌腱縮短所造成的角旋轉，因而可能削弱屈曲行程。

研究曾在精英攀岩者觀察到約百分之二十六的屈肌滑車過度伸展或弓弦化，較常見於中指與環指。這是特定族群的研究比例，不能直接當作一般手部發生率。

## 腕隧道與正中神經 {#carpal-tunnel}

九條手指外在屈肌腱與正中神經通過腕隧道。腕隧道狹窄且缺乏順應性，滑液鞘腫脹、內容物擁擠、反覆用力握持或腕部彎曲，都可能提高神經受壓與牽扯的機會。

腕隧道症候群常表現為正中神經分布的疼痛與感覺異常，也可能有魚際肌無力與萎縮；原書強調成因多因素，還包括某些結締組織纖維化，使肌腱與神經的自由滑動受限。症狀與機制不能僅由某一項活動推定。

這個例子顯示，手部動作不是肌肉單獨完成。滑液鞘、腕隧道壁與神經可改變肌腱的可動性與感覺回饋，進而影響抓握力量與精細操弄。

## 只彎一個指節，近端也要有人穩住 {#proximal-stability}

假設只想讓 PIP 彎曲，指淺屈肌的肌腱卻同時跨過 MCP 與手腕。原書圖 8.36 把三處力臂設為 0.75、1、1.25 cm；同樣 20 N 的肌腱張力，便分別產生 15、20、25 N·cm 的屈曲力矩。

這裡變大的是不同轉軸上的力矩，肌腱張力仍是同一個 20 N。指伸肌與必要的腕伸肌需要抵消近端不想要的屈曲傾向，才能讓主要動作出現在 PIP。近端穩定不足，會干擾遠端精細動作。

把下圖的張力調大，可以看到三處力矩一起增加。它們分別作用在不同關節，不能把三個數字直接相加，也不能用這條肌腱的單獨作用預言最後姿勢。

## 腕部位置與肌腱固定作用 {#tenodesis}

外在屈肌跨過腕掌側。主動伸腕會拉長屈肌，使手指與拇指被動屈曲；健康受試者把腕由完全屈曲伸到完全伸展時，DIP 平均自動屈約二十度、PIP 約五十度、MCP 約三十五度。

反向地，腕完全屈曲會拉長外在伸肌，使手指被動伸展。這種一條多關節肌跨一關節後在其他關節產生被動運動的現象稱為腱固定作用（tenodesis action）。角度是平均觀察，不是每人固定值。

C6 四肢癱瘓者若腕伸肌仍有神經支配，可利用腕屈開手、再主動伸腕拉緊癱瘓屈肌來握住杯子。這是力學與殘存動作的例子，功能結果仍受感覺、關節被動活動與個別神經損傷影響。

## 外在伸肌與伸肌腱膜 {#extensor-mechanism}

指伸肌、食指伸肌與小指伸肌的肌腱經腕背滑液腔，再由掌骨背側前往手指。伸肌腱之間有腱間連結，能穩定進入 MCP 的角度，也可能限制單指完全獨立。

遠端伸肌腱不像屈肌那樣由明確滑車通道包住，而是融入每指背側的纖維擴張，稱伸肌腱膜（extensor mechanism）。它承接外在伸肌與多數手內在肌，將近側拉力分配到 MCP、PIP 與 DIP。

伸肌腱膜包含中央束、側束、背側腱帽與連接韌帶。其完整位置能讓肌腱接近關節轉軸；若側束、中央束或三角韌帶失去支持，肌腱路徑改變便會把原本的伸展力轉成屈曲或過伸力矩。
{{< reading-source from="296" to="298" >}}

## 中央束與側束，把拉力送到不同指節 {#extensor-components}

指伸肌到指背後，主要肌腱延續成中央束，附著在中節指骨基底的背側。在跨過 PIP 前分出的兩條側束，向遠端合成終末腱，再附著到遠節指骨基底；因此同一套結構能把伸展作用送到 PIP 與 DIP。

靠近 MCP 的背側腱帽，則幫助把伸肌腱維持在關節背側。橫向纖維連到掌側板，形成支持近節指骨的吊帶；其中靠近中央的矢狀束穩定伸肌腱的位置。

蚓狀肌與骨間肌主要經背側腱帽的斜向纖維連入側束。它們的拉力因而能進入同一套伸肌腱膜；中央束、側束與腱帽的分工，比「一條伸肌拉直整根手指」更接近原書描述。


可對讀[Nordin 的伸肌腱膜分工]({{< relref "/library/basic-biomechanics/ch14/index.md" >}}#extensor-assembly)，從另一冊的負荷觀點接著理解。

## 伸拇指時，手腕需要平衡橈偏傾向 {#coordination}

拇長伸肌、拇短伸肌與拇長外展肌從前臂背側走向拇指，但末端附著不同。拇長伸肌到遠節指骨，可伸展 IP、MCP 與 CMC；拇短伸肌到近節指骨，主要作用在 MCP 與 CMC；拇長外展肌主要附著在第一掌骨基底，作用集中在 CMC。

「外展肌」仍可能兼有伸展作用，「伸肌」也可能兼有內收作用。原書以肌腱相對轉軸的位置說明這些組合；拇長伸肌還能把拇指由對掌帶回伸展、外旋與內收的復位方向。

拇長伸肌與拇長外展肌也會對手腕產生明顯橈偏力矩。快速或完全伸拇指時，尺側方向的肌肉需要協助穩住手腕，例如原書描述的尺側腕屈肌。指端動作與近端穩定，因而是同一件工作的不同部分。

## 魚際與小魚際 {#thenar-hypothenar}

魚際肌包括拇短外展肌、拇短屈肌與拇對掌肌，主要把拇指帶入對掌的外展、屈曲與內旋組合。原書本章討論拇短屈肌時，只取它的淺頭；神經支配的概括也依這個範圍閱讀。拇對掌肌附著在第一掌骨，因而能直接控制 CMC 的內旋；正中神經傷害可能削弱這組肌肉的功能，對掌與橈側指尖感覺都可能受影響。

小魚際肌包括小指屈肌、外展肌、對掌肌與掌短肌。它們可抬高尺側掌緣、加深遠側橫弓，並使第五掌骨朝中指方向旋轉；尺神經傷害會削弱小魚際隆起與杯狀抓握。

拇收肌有斜頭與橫頭，位於第二、第三掌骨掌側，能產生強大的拇指 CMC 屈曲與內收力矩，協助夾住物品或合上剪刀。其作用是力臂與肌肉截面共同決定的結果，不宜只以肌肉大小判斷。
{{< reading-source from="299" to="302" >}}

## 蚓狀肌與骨間肌 {#intrinsic-muscles}

四條蚓狀肌起於 FDP 腱，向掌側經過 MCP，再接到伸肌腱膜側束。它們因此能屈 MCP、伸 PIP 與 DIP；這個看似相反的組合，來自肌腱在 MCP 掌側、IP 背側的路徑。

蚓狀肌纖維長度相對肌肉長度較大而截面小，適合小力量、長距離調節。第一蚓狀肌的肌梭密度約為手部骨間肌三倍、肱二頭肌八倍，提示它也能提供複雜動作的長度回饋。

掌側骨間肌把食指、環指與小指帶向中線；背側骨間肌使食指與環指遠離中線，也能將中指帶向橈側或尺側。小指外展則主要由小指外展肌完成。骨間肌也同時屈 MCP、伸 IP，並像動態副韌帶一樣協助限制 MCP 過度旋轉。
{{< reading-source from="302" to="304" >}}

## 內在與外在肌的相反姿勢 {#intrinsic-plus}

蚓狀肌與骨間肌同步收縮可形成 MCP 屈曲、IP 伸展的內在肌優勢姿勢；外在伸肌與屈肌的組合則可造成 MCP 過伸與 IP 屈曲的外在肌優勢姿勢。功能動作通常混合兩者，而非只使用一組。

手指動作的確切時序會受速度、力量、物體形狀與重量，以及個體策略影響。相同外觀動作可以由不同肌肉組合完成，因此肌電圖、解剖與模型結果應被視為互補證據，不能把單一模式當成唯一答案。

病理姿勢反而能揭示正常協調：失去尺神經支配的內在肌後，指伸肌只把 MCP 拉到過伸，IP 卻屈曲成爪狀。若以外力阻止 MCP 過伸，指伸肌便較能把力傳到 IP，顯示近側關節位置是遠端動作的條件。
{{< reading-source from="304" to="306" >}}

## 開手：伸指時序 {#finger-opening}

開手常是抓握前準備。最大阻力往往來自被拉長的外在屈肌黏彈性回縮，而非重力；指伸肌先主要伸 MCP，之後內在肌協助伸 PIP 與 DIP，同時在 MCP 產生屈曲力矩以防止指伸肌過伸 MCP。

快速完全伸指時，腕屈肌也會收縮，抵消指伸肌在腕部的伸腕趨勢，使腕稍微屈曲並維持指伸肌較適當的長度。避免不必要的腕伸與 MCP 過伸，有助於更遠端指節完成伸展。

斜支持韌帶（ORL）由 PIP 掌側走向 DIP 背側。原書指出它的相對重要性仍有爭議，並以伸 PIP 時受拉、向遠端傳力的模型說明它可能如何協助伸 DIP；若因關節炎、結締組織病或創傷變緊，PIP 被動伸展時 DIP 也可能被牽著伸直。
{{< reading-source from="305" to="307" >}}

## 關手：屈指與握拳 {#finger-closing}

抗阻或快速屈指主要需要 FDP、FDS，並有骨間肌參與。FDP 將屈曲作用帶到 DIP，FDS 主要作用在 PIP，兩者也都對 MCP 產生屈曲力矩。隨手指彎曲，伸肌腱膜向遠端移動；原書此例的蚓狀肌主要被動受拉，在兩端被拉長時可產生小的被動 MCP 屈曲力矩。

強握需要腕伸肌協同，抵消屈指肌造成的腕屈趨勢，也維持屈肌較有利的長度。若腕伸肌癱瘓，屈指時腕會屈曲，屈肌縮短與指伸肌被拉長共同削弱有效握力。

指伸肌在合手時也會啟動，對 MCP 提供伸展方向的制動，讓長屈肌能把作用分配到更遠端。原書描述一般閉手時 PIP／DIP 先開始屈曲，MCP 緊接著跟上；內在肌癱瘓且 MCP 長期過伸時，MCP 屈曲可能延遲，手指由遠端向近端捲入，物體可能被推出掌外。
{{< reading-source from="307" to="308" >}}

## 手作為效應器 {#grasp-task}

手可作支撐平台、操弄工具或抓握器。操弄可為重複而粗略的敲擊，也可為連續流暢的書寫與縫紉；多數任務混合兩者，所需力量與精確度會隨物體和目的改變。

力量型抓握以高穩定和大力量為主，常用於圓柱或球形物與鎚子；指屈肌、骨間肌、拇收肌與拇屈肌提供主要力量，腕伸肌穩定腕。精細抓握則讓拇指部分外展、手指部分屈曲，以較低力量控制脆弱或細小物體。

力量型側捏把物體夾在拇指與食指側緣；精細捏可用指尖對指尖或指腹對指腹；鉤狀抓握則不需拇指，以 PIP 與 DIP 部分屈曲承受行李帶等長時間負荷。掌弓形狀會隨任務調整接觸面。

可對讀[Nordin 的力量型與精細操作]({{< relref "/library/basic-biomechanics/ch14/index.md" >}}#power-precision)，從另一冊的負荷觀點接著理解。

## 類風濕的拇指鋸齒變形 {#ra-thumb-zigzag}

慢性滑膜炎會降低關節周圍結締組織的抗拉強度。原書指出，即使輕敲鍵盤，MCP 也可能承受超過 11 N、約 2.5 磅的力；當組織不能分散反覆外力與肌力，關節便可能失準、不穩與變形。

一種拇指鋸齒變形是 CMC 屈曲內收、MCP 過伸、IP 屈曲。CMC 韌帶變弱後，第一掌骨基底向橈側或背橈側脫位；拇收肌與短屈肌把掌骨固定在掌面，為了把拇指拉出掌面，MCP 代償過伸。

MCP 掌側板被拉長後，拇長伸肌與拇短伸肌的伸展力臂增加，進一步推動過伸；拇長屈肌被拉緊，則使 IP 維持屈曲。這是多關節方向交替崩塌的機制示例，不是單一關節症狀名稱。
{{< reading-source from="310" to="311" >}}

## MCP 掌側脫位與尺偏 {#ra-mcp}

手指屈曲時，FDS 與 FDP 在 MCP 掌側彎曲，對掌側板、A1 滑車與副韌帶形成掌側弓弦力。健康組織可分散此力；類風濕削弱副韌帶後，近節指骨可能向掌側平移並脫位，連帶壓平縱弓與橫弓。

尺偏是近節指骨過度尺側偏移與平移。重力、掌骨頭斜面、屈肌腱偏尺側的拉線，以及拇指夾捏對橈側手指施加的尺向力，平時就提供偏移傾向；完整背側腱帽橫纖維與橈側副韌帶能限制它。

若背側腱帽橫纖維破裂，指伸肌腱向尺側移，力臂增加後反過來放大尺偏；腱再向 MCP 掌側移，可能產生屈曲力矩，形成尺偏與掌側脫位的連鎖。這是力線改變造成的自我加強過程。
{{< reading-source from="311" to="313" >}}

## 天鵝頸與鈕扣孔，是不同的關節方向組合 {#ra-zigzag-fingers}

天鵝頸變形（swan-neck deformity）是 PIP 過伸、DIP 屈曲。內在肌纖維化或收縮，加上 PIP 掌側板變弱，會把伸展力矩推向過伸；PIP 過伸又使側束背側弓弦化，進一步增加內在肌伸 PIP 的力臂。

鈕扣孔變形（boutonnière deformity）則相反，是 PIP 屈曲、DIP 過伸。中央束與三角韌帶破裂或變薄，側束向 PIP 轉軸掌側滑移，原本的伸展力改成屈曲力；側束張力又使 DIP 難以屈曲。

兩者都可見於嚴重類風濕性關節炎。原書特別指出，天鵝頸也可能與掌側板創傷或內在肌張力過高有關；鈕扣孔則要回到中央束與側束的完整性理解，不能把兩者的成因清單直接互換。名稱描述的是關節方向組合，不能由外觀直接判定病因。
{{< reading-source from="313" to="315" >}}

## 腕與手的連鎖失穩 {#wrist-hand-chain}

腕至手指是一串連續關節，近側失穩可能改變遠側肌腱的對線。類風濕或創傷使腕骨向尺側移，掌骨相對轉向橈側，會增加指伸肌腱對 MCP 的尺向弓弦力，從而加重尺偏。

這個例子提醒評估者不能只看變形所在的 MCP。伸肌腱是否仍位於掌骨頭背側中央、腕骨是否平移、橈尺偏力矩如何改變，都是判讀手指排列的近側條件。

原書把路徑機制與臨床處置分開描述；本章在此只保留力學關係，不把特定手術、支具或恢復時間當成所有人的固定方案。

## 神經損傷與腱移位案例 {#nerve-clinical-link}

正中、尺與橈神經可能受壓、牽拉、骨折割傷或穿刺傷，造成不同程度的肌肉癱瘓、感覺喪失與皮膚營養變化。正中神經在腕部完全斷裂時，魚際肌癱瘓，拇指對掌消失，並可能被尺神經支配的拇收肌與橈神經支配的拇長伸肌拉向內收與外旋。

原書病例說明，若癱瘓看來持久，外科可把仍有神經支配的肌腱重新導向以恢復部分作用，例如將環指 FDS 移至拇指 MCP 附近以作對掌成形。手術選擇取決於損傷位置、剩餘感覺、關節被動活動與可用肌腱，並非單靠一條神經名稱決定。

肌腱移位的生物力學重點是力與內力臂共同決定力矩。原書提到周邊神經在理想條件下可約每日再生一毫米、約每月一英吋，但這是生理估計；案例本身不能提供個人預後或復健時程。

## 弧度與肌腱行程 {#radian-excursion}

一弧度定義為圓心角，其弧長等於半徑，數值約五十七點三度。若肌腱像繩子繞過關節滑輪，關節被動轉約五十七度時，肌腱行程可近似該肌肉的內力臂；關係式為 s＝θ × r，其中 θ 要用弧度表示，而不是把角度的度數直接代入。

這種肌腱行程法曾用於屍體與手術現場估計內力臂，但關節面並非完美球面，估值帶有誤差。它適合比較同一個人的肌腱位置與力學，不應被讀成所有活動範圍內都完全固定的力臂。

原書臨床連結把幾何模型放在腱移位決策背景中，目的在說明肌腱離轉軸太近或太遠會改變力量與角位移的取捨，而非提出一般人的治療規則。

## 滑車損傷的路徑機制 {#pulley-clinical}

完整 A2、A3、A4 滑車時，FDP 在 PIP 的力臂約零點七五公分；若肌肉縮短一點五公分，理論上可造成約一百一十四度、即兩弧度的 PIP 屈曲。這是幾何近似，數字來自原書模型而非所有手指的實測值。

若 A2 與 A3 破裂，FDP 可弓弦化，PIP 力臂理論上增至一點五公分；同樣一點五公分縮短只產生約五十七度、即一弧度屈曲，約為完整滑車情況的一半。力學優勢增加，卻降低肌腱縮短轉成關節角度的效率。

原書以此解釋滑車破裂時即使出力也可能無法充分屈曲，並以 A2、A4 的功能重要性作臨床背景。這段保留研究模型的「理論上」限制，不把圖示計算當作個別檢查結果。

## 側捏算例：食指也需要足夠的反向支持 {#key-pinch-mechanics}

側捏把物體夾在拇指與食指側緣之間。拇指肌群提供捏取力，第一背側骨間肌則透過食指 MCP 的外展作用抵住它。原書圖 8.65 把外力臂設為 5 cm、內力臂設為 1 cm；若只由這條肌肉平衡，肌肉力便需約為指端力的 5 倍。

原書接著檢驗這個單肌模型：45 N 的捏力會要求約 225 N 肌肉力，但以 28 N/cm² 的比張力乘上 3.8 cm² 橫斷面積，估計只有約 106 N。作者因此推論，最大用力側捏可能還需要其他肌肉提供外展力矩；225 N 是模型需求，並非已證明單條肌肉能產生的實測值。

尺神經受損時，拇收肌與骨間肌的作用可能一起減少。原書描述以拇長屈肌代償、使拇指 IP 更屈曲的 Froment 徵象；它說明剩餘肌肉如何改變姿勢，也提醒我們，拇指有出力仍不表示食指側的支持已經恢復。

## 把手指接回整條上肢的任務 {#chapter-synthesis}

讀完這章，可以用一個拿杯子的動作把各層接起來：中央掌骨提供底座，周邊掌骨調整掌弓，拇指對掌建立相向的接觸，MCP 與 IP 配合物體形狀。伸屈肌與內在肌協調張力，感覺再協助調整抓握力量。

肌肉名稱只告訴我們部分作用。判讀一個動作，還要問肌腱在轉軸哪一側、近端是否穩住、滑行是否足夠，以及其他關節正在做什麼。原書的病例與算例把這些平常看不見的條件顯現出來。
