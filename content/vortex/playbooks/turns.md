## 第一頁：一張圖讀完

```
起跳 → 入水 → 水下推進 → 出水（Breakout）→ 第一划水
轉身 → 進牆 → 翻滾/觸牆 → 蹬牆 → 水下推進 → Breakout → 第一划水
        ↓        ↓          ↓        ↓               ↓
      timing   執行        力學    最強預測因子     不換氣
      最常錯   流線型     力向量   (見下方)         (見下方)
```

**最強單一預測因子**：水下推進速度（不是離台時間、不是飛行距離）。多數教練投入錯了優先序。

**三大持續性錯誤**（每個年齡段都會犯）：
1. 推蹬「越用力越快」（忽略流線型與力向量品質）
2. Breakout 多踢慢上來避免掉速（事實是水下越久速度衰減越多）
3. 起跳後第一划要呼吸補氣（破壞最快段）

## 起跳 STARTS

### A. Track Start 設置（菁英預設）

Grab Start 自 2000 年代已退役；現代菁英全用 Track Start，含**重心前傾 vs 重心後仰**兩種變體。

| 變體 | 適合誰 | 機制 | 代表選手 |
|---|---|---|---|
| **前傾** | 海豚踢強、垂直起跳普通 | 反應時間最短、離台快、推進力較弱 | Sjostrom、Kromowidjojo |
| **後仰** | 垂直起跳強、肌肉爆發力高 | 三段加速（手上拉+後腳推+前腳推），需要良好垂直起跳能力配合 | Dressel、Tandy |

**Set position 關鍵**：① 臀高於肩（重心前移）；② 膝蓋角度按個人肌肉特性（無通用數字，研究確立 100–120° 為群體均值）；③ 圓背（vs 平背：實測圓背入水距離 +5%、12m 快 2%）。

> 進一步：tech.1 / tech.5 / tech.41

### B. 三個 Coupling 動作（決定能不能再快）

起跳推進主力是雙腳蹬板+雙手上拉，但三個 coupling 動作能放大這些推進力：

1. **後腿踢**（最大）：後腿 20–40 磅快速上揚產生大量動能。**絕大多數泳者完全沒意識到自己後腿在幹嘛**——是進步空間最大的 coupling
2. **大圓直臂繞臂**（次大）：能量與「手臂長度² × 角速度²」成正比，比小圓彎肘多 37% peak acceleration（Niko Obrovac VM 量測）
3. **抬頭**（爭議派）：11 磅頭快速向上抬升 + 維持遠視，能增加飛行距離 +11%、12m 快 3%（Amanda Kendall VM）

**抬頭爭議**：兩派並陳，不是「對 vs 錯」。靜態派要求中立、動態派要求抬頭。對應 err10——絕對化口令兩派都過度執行，應依選手核心控制與飛行軌跡偏好評估。

> 進一步：tech.43

### C. 入水與 Hyperstreamline

入水阻力按速度平方上升，所以入水姿勢構造比一般 streamline 嚴格得多。三段要件：

| 元素 | 物理目標 | 量測 |
|---|---|---|
| **Hyperstreamline** | 下巴貼胸、肘部夾緊、手腕重疊、肩部 sub-luxation | 約二十人有一個能做到雙肘觸碰（"unicorn"）；近距離已足夠 |
| **髖屈 15°** | 上半身略下傾、下身水平 | 髖屈 <10° = 入水太陡太深；>30° = 入水太遠太深 |
| **腳尖伸直** | 完全 plantar flexion | 腳掌懸掛（未蹠屈）增加 41% 阻力（PDM 量測 @ 2.3 m/s）—— **最常見的入水錯誤** |

最常被忽略：**腳尖**。輕微膝彎可幫助腳尖指得更垂直。

> 進一步：tech.42 / tech.10 / tech.11

### D. 仰式起跳

仰式起跳特殊性：髖部高度是核心表現變數。需要：① 臀部先出水再蹬腿；② 拱背越過水面但不過度；③ 雙腿/雙腳完全出水後再入水（Backstroke Ledge 改善入水距離但不增加推力）。

**仰式起跳 progression drills（Race Club）**：
- STEL1 階梯式起跳（從池梯最低踏板逐步上）
- STEL2 腿驅動跳（強調腿/髖往上爆發，手是被動的）
- STEL3 踢沙灘球（教練拿球懸在拋物線高點當時機標靶）

> 進一步：tech.17-20

## 轉身 TURNS

### 核心目標
**速度損失最小化**——而非「轉得快」。研究確認推蹬力道解釋約 42% 表現變異，**推蹬方向與重心對齊**的相關係數 r=0.76、**流線型品質**是力量轉換的前提條件。優先序錯誤是教練普遍盲點。

**正確優先序**：流線型時機 → 推蹬方向 → 推蹬力道。

### A. 自由式翻滾轉身

**Approach（進牆）**：
- 計步判距，**頭絕對不抬**——抬頭破壞翻滾旋轉動量、提前減速
- 進牆速度保護：最後一划完整、距離不對補踢腿（不是縮短最後一划）
- 翻滾啟動時機是關鍵：太早 → 觸牆角度過垂直；太晚 → 損失進牆速度

**Execution（翻滾 + 觸牆）**：
- 流線型應在腳觸牆前完成，**不是推出後才整理**（這是常見 err6）
- 膝蓋屈曲 100–120° 是最優觸牆角度
- 推蹬力向量必須對齊重心軌跡（r=0.76，比力道大小更關鍵）

**Breakout（出水）**：
- 詳見下方 Breakout 章節

**最常見 4 個錯誤**：
1. err6 觸牆蹬出之後才做流線型 → 應該觸牆前完成
2. err7 仰式計步固定數步無視速度 → 須分速度標定
3. err9 推牆力道越大越快 → 力向量與流線型比力道重要得多
4. err11 轉身越快越好 → approach 速度過快無法精確翻滾

> 進一步：tech.21-26 / tech.39 / err6, 9, 11

### B. 仰式翻身轉身

仰式看不到牆，**靠計步而非視覺**——但計步**沒有跨選手通用數字**，需分速度標定。

關鍵 drill：**ST4 仰式旗下數划手**（從距牆 5m 旗標開始固定划手數），加蛙鞋以比賽速度測試以校正高速。**STSpat1 閉眼靠水聲判斷牆距** 是 ST4 的聽覺進階版（菁英級）。

仰式翻身規則：俯臥觸牆**不違規**（菁英多用 crossover 轉法）。翻滾動作與自由式相同。

> 進一步：tech.27-28 / drills ST4, STSpat1

### C. 蛙式/蝶式開放轉身

蛙式轉身特殊：
- **觸牆深度 30–40 cm 最優**——過深或過淺都損失蹬牆品質
- err8「往下沉找牆」是常見錯誤，造成觸牆深度過深
- **Pullout 三種技術無統計顯著差異**：個人測試決定，不要套用「最佳技術」
- 水下滑行最優深度 0.4–0.6 m
- err13 「pullout 完全靜止才划手」錯失最佳推進力疊加時機

蝶式轉身與蛙式類似但 pullout 是蝶腳不是蛙腳。

> 進一步：tech.29-30 / err5, 8, 13

### D. IM 轉換（個人混合式 4 段）

**蝶→背**：四式 IM 中最快的轉身。

**背→蛙**：
- 規則：觸牆時仰臥、離牆時俯臥，**旋轉在牆上完成**
- 三種轉法：Crossover / Bucket / Open
- Crossover 推出速度最高，但 **7.5m 成績無顯著差異**——不要為了「最快」強制換轉法
- 各轉法適用情境不同
- 常見犯規：**肩部提前過垂直面**（在牆前轉身）

**蝶→背三大效率損失**：
1. 觸牆停頓確認
2. 縮腿路徑過長造成旋轉慢
3. 觸牆後抬頭換氣打斷旋轉動量

正確：觸牆同時縮腿、快速收膝、**全程閉氣**

> 進一步：tech.31-35 / tech.38

## 水下推進 + Breakout

### 水下是最強起跳預測因子

**跨所有競技層級（含 Paralympic）**：水下階段速度是「總起跳時間（到 15m）」的最強預測因子，勝過離台時間與飛行距離。

- S10/Olympic 級水下約 3 m/s
- S8/S9 因 streamline 維持困難常低 40–50%

**起跳訓練優先序**：水下姿勢 + 第一下海豚踢時機 >> 離台爆發力。對能力較有限的選手，這個排序差異尤其關鍵。

### Breakout 時機決策

err12「Breakout 多踢幾下慢慢上來避免掉速」是普遍錯誤。事實：

- 水下推進速度從蹬牆瞬間（5–6 m/s）就開始衰減
- 海豚踢主要功能是**維持速度**而非加速
- 當水下速度衰減到接近游速時，繼續水下就是淨損失
- 多數選手最佳出水點在 5–10 公尺；超過 12 公尺通常已淨損失

**正確處方**：個別化測試。用秒錶與標記比較不同距離出水的 15m 總時間，找個人最快出水點。

### 自由式 Breakout 七要點

第一划必須與最後一下海豚下踢同步啟動（不是過渡踢腿期）：

1. 第一划 + 最後一下海豚下踢**同步**
2. 海豚踢完才轉強力捷式踢
3. 維持 hyperstreamline 直到第一划真正開始
4. 第一划手肘**內側**發動（不外掃）
5. 前伸手繼續往前送、指緊掌平、肘不彎
6. 下巴貼胸到 breakout 完成才能抬
7. **第一划不換氣**（無論距離；對應 err14 反例）

> 進一步：tech.44 / err12, 14

│   ├─ 太快 → 翻滾不精確 → 練 approach 配速控制

│   │
│   └─ OK → 進 Q2
│
├─ Q2：翻滾旋轉時機？
│   │
│   ├─ 太早 → 觸牆角度過垂直 → 練翻滾啟動點判讀
│   │         （drill：ST1 中池翻滾、ST2 翻牆踩牆）
│   │
│   ├─ 太晚 → 進牆速度浪費 → 改善計步精確度
│   │
│   └─ OK → 進 Q3
│
├─ Q3：流線型品質？
│   │
│   ├─ 推蹬時還在「整理姿勢」 → 流線型須在腳觸牆前完成
│   │   （這是 err6 最普遍錯誤）
│   │
│   └─ OK → 進 Q4
│
├─ Q4：推蹬力向量？
│   │
│   ├─ 力沒對齊重心軌跡 → 練蹬牆對齊
│   │   （r=0.76 比力道大小更關鍵）
│   │
│   └─ OK → 進 Q5
│
└─ Q5：水下推進與 Breakout？
    │
    ├─ 太晚出水 → 水下速度衰減 → 個別化測試最佳出水點

    ├─ 太早出水 → 推進浪費 → 同上
    │

## Drill 階梯

**基礎建立**：ST1 中池翻滾 → ST2 翻牆踩牆（拆解翻滾本身與牆邊執行）

**進階流線**：ST3 蹬牆流線測距（用「滑多遠」當客觀回饋）

**仰式專項**：ST4 旗下數划手 → STSpat1 閉眼靠水聲（菁英）

**整合**：ST5 蹬牆轉體出水（自由式翻身蹬牆時是仰／側躺，練水下旋轉接 breakout）

## 額外注意

### 起跳測量指標不一致
反應時間 / 入水速度 / 15m 時間可能給出**相反結論**。所以只看一個指標可能誤判，需同時看多個。

### Paralympic 處方按級別個別化
- S8–S9：對划頻（SR）高度敏感、對划距（SL）相對不敏感 → 處方拉高頻
- S10/S7：高度依賴 SL → 處方拉長 stroke
- 「Distance Per Stroke 越大越好」是某類選手才適用的部分真理

> 進一步：tech.46

### 神經肌肉控制限制下的退化（CP 選手等）
30 秒後系統性技術退化是神經特性、不是體能。**配速策略反轉**：前段保留以維持末段技術品質。

> 進一步：free.tech.31
