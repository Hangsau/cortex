> **定位**：[〈混合式泳式段取捨〉](../im-legs/)看的是同一趟混合式裡，四個泳式段怎麼一起動。這篇往外看：混合式的四個泳式段，跟蝶、仰、蛙、自四個單項有什麼關係？混合式選手去游蛙式項目，成績怎樣？一個泳式進步了，會不會帶到別的泳式？對應的教學決定是混合式選手的弱項補強和報名選項。
>
> **讀法**：數字都是渦流計畫自己分析公開比賽成績得到的，屬 🔵 推論層級；對原因的解釋標 🔴。分析前先寫好計畫；選手隨機分兩半，一半用來找錯，程式定案後另一半只跑一次。下面是第二半的結果，括號內是第一半。這些分析沒有經過同儕審查。
>
> **本筆記不取代知識點**，是研究層素材。

## 研究方法

**資料**：三個來源程度不同，**分開算、不合併**，看結論在三種程度是否都成立。

| 來源 | 程度 | 範圍 |
|---|---|---|
| 日本全國大賽 2008–2026 | 全國賽 | 長池＋短池；每半約 2,900 位 200 混合式選手 |
| 台灣中華泳協 2026 | 分區賽到全國賽、分齡為主 | 15 場，只有長池有分段；約 2,800 位 200 混合式選手 |
| 世界泳聯 2023–2026 | 世界級賽事（含世青） | 長池＋短池；約 770 位 200 混合式選手 |

**相對成績**：跟同池長、同性別、同年齡（台灣用年齡組）的人比，快多少 %。混合式每個泳式段也用同樣的方式，跟同齡同性別的人比。每人每季取最好的一趟。

**四個問題**：
1. 混合式同一組相鄰名次的兩人，差距落在哪一個泳式段？
2. 混合式的四個泳式段，各自最能預測哪一個單項的成績？
3. 混合式選手去游 200 蛙：蛙式段是自己強項的人，200 蛙排名會不會比混合式更前面？混合式的蛙式段大約等於自己單項蛙式的什麼速度？
4. 同一個人隔一年：某個單項進步了，混合式哪一段跟著快？（只有日本資料夠）

## 結果 🔵

### 三個來源一起看

| 結論 | 日本 | 台灣 | 世界泳聯 | 判定 |
|---|---|---|---|---|
| 蛙式最獨立 | ✓ | ✓ | ✓ | 三種程度都成立 |
| 蛙式段強的混合式選手，200 蛙排名比混合式更前面 | ✓ | ✓ | ✓ | 三種程度都成立 |
| 混合式蛙式段 ≈ 200 蛙平均每 50 × 1.02–1.045 | ✓ | ✓ | 人數不足 | 兩個來源一致 |
| 200 混合式的差距，蛙式段占最多 | ✓ | ✗ | ✗ | 只在日本穩定 |
| 蝶式段強的人 200 蛙稍好 | ✓ | ✗ | ✓（弱） | 不穩定 |
| 蛙式的進步集中到混合式的蛙式段 | ✓ | 無法做 | 人數不足 | 只有日本能回答 |

### 1. 蛙式最獨立

用混合式的四個泳式段，預測 200 蛙（標準化係數）：

| | 蝶式段 | 仰式段 | 蛙式段 | 自由式段 |
|---|---|---|---|---|
| 日本 | 0.31 | −0.06 | **0.61**（0.69） | −0.07 |
| 台灣 | 0.06 | 0.14 | **0.89**（0.77） | −0.18 |
| 世界泳聯 | 0.19 | −0.03 | **0.79**（0.73） | −0.03 |

- 三個來源都一樣：200 蛙幾乎只跟混合式的蛙式段有關，仰式段、自由式段預測不了。
- 反過來，混合式的蛙式段也預測不了 200 蝶、仰、自（三個來源都在 −0.09～0.11）。
- 其他泳式就沒有這麼乾淨，例如台灣的 200 蝶，由仰式段和蝶式段預測得差不多。
- 日本資料分性別、分年齡（15 歲以下／16 歲以上）再看，四組都一樣（計畫外分析）。

### 2. 混合式選手游 200 蛙

| | 日本 | 台灣 | 世界泳聯 |
|---|---|---|---|
| 蛙式段比自己其他三段每強 1% → 200 蛙的相對成績比自己 200 混合式多好 | **0.41%**（0.44） | **0.63%**（0.52） | **0.48%**（0.50） |
| 混合式蛙式段 ÷ 自己 200 蛙平均每 50（中位數） | 1.032–1.046 | 1.022–1.041 | 人數不足 |
| 混合式蛙式段 ÷ 自己 100 蛙平均每 50（中位數） | 1.104–1.121 | 1.111–1.139 | 人數不足 |
| 200 蛙參賽者同季也游 200 混合式 | 10–12% | 74% | 20–26% |

- 混合式蛙式段前面已經游了 100 m、而且沒有跳水，所以一定比單項慢。
- 「有游混合式的人，200 蛙比較好」只在日本看到（100 蛙程度相同時好 0.37%），世界泳聯看不出來，台灣幾乎人人都游混合式、沒有對照組，所以不當結論。

### 3. 混合式的差距落在哪一段

相鄰名次的差距，各段占的 %（200 混合式；蝶／仰／蛙／自）：

| | 驗證半 | 探索半的蛙式段 |
|---|---|---|
| 日本 長池 | 17／28／**34**／21 | 36 |
| 日本 短池 | 17／27／**34**／21 | 32 |
| 台灣 長池 | 24／25／27／25 | 34 |
| 世界泳聯 長池 | 18／**31**／28／23 | 38 |
| 世界泳聯 短池 | 19／30／29／22 | 33 |

- 日本兩半都是蛙式段最多，約三分之一，比蛙式段占全程時間的比例（約 29%）還多。
- 台灣和世界泳聯的兩半不一致：探索半蛙式段最多，驗證半則四段差不多，或仰式段比較多。
- 所以「混合式的勝負在蛙式段」只能說日本全國賽層級是這樣，不能一般化。[〈泳式之間的關係〉](../cross-stroke-relations/)寫的「約 34%」也是同樣的情況。

### 4. 進步會不會跨泳式傳過去（只有日本）

| 單項進步 1% → | 蝶式段 | 仰式段 | 蛙式段 | 自由式段 | 人數 |
|---|---|---|---|---|---|
| 200 蝶 | 0.32 | 0.30 | 0.35 | 0.48 | 93 |
| 200 仰 | 0.28 | 0.43 | 0.56 | 0.43 | 74 |
| **200 蛙** | 0.22 | 0.24 | **0.53**（0.52） | 0.48 | 109 |
| 200 自 | 0.40 | 0.46 | 0.43 | 0.56 | 166 |

- 只有蛙式的進步明顯集中在同泳式那一段（比蝶式段、仰式段多 0.3），而且接在後面的自由式段也一起快。
- 蝶、仰、自進步時，混合式四段都一起快，沒有特別集中在哪一段。
- 台灣只有一季、世界泳聯人數不足，這一題目前只有日本的答案。

## 結論

1. **蛙式是自成一格的泳式**：日本全國賽、台灣分齡、世界級賽事三種程度都一樣。其他泳式好，不代表蛙式好；蛙式好，也不代表其他泳式好。
2. **混合式選手的蛙式項目，看他混合式的蛙式段就知道**：蛙式段是自己強項的人，200 蛙的排名通常比混合式更前面，三種程度都成立。
3. **換算**：混合式蛙式段約為自己 200 蛙平均每 50 的 1.02–1.045 倍、100 蛙平均每 50 的 1.10–1.14 倍。
4. **「混合式的勝負在蛙式段」只在日本全國賽穩定**；台灣分齡與世界級賽事不一定，要看自己那一組實際差在哪一段。
5. 🔴 蛙式的划水和踢腿跟其他三式差最多，所以能力最難互相轉移。資料無法確認原因。

## 應用推薦

| 情況 | 做法 |
|---|---|
| 估混合式選手的蛙式項目 | 看他混合式的蛙式段，不要看其他泳式段 |
| 混合式選手要不要加報 200 蛙 | 蛙式段比自己其他三段強，就值得報；200 蛙的排名通常比混合式更前面 |
| 估混合式蛙式段該游多快 | 自己 200 蛙平均每 50 × 1.02–1.045；或 100 蛙平均每 50 × 1.10–1.14 |
| 用其他泳式推估蛙式 | 推不準，蛙式要另外評估 |
| 混合式要贏，先補哪一段 | 不要預設是蛙式段；把自己那一組相鄰名次的分段拿來比，看實際差在哪一段 |

## 限制

- 相關，不是因果。
- 日本是全國大賽層級、世界泳聯是世界級賽事（含世青），都是選過的人。台灣包含分區賽、程度最廣，但只有 2026 一季、只有長池，而且是用姓名＋性別＋單位辨識人。
- 進步那一題只有日本，每格 74–166 人，區間寬。
- 「蛙式最獨立」是扣掉其他段之後各段單獨的貢獻，跟[〈泳式之間的關係〉](../cross-stroke-relations/)③ 的原始相關不是同一種量法，不能拿來互相推翻或確認。
