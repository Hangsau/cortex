## 0. 為什麼心理層存在，又為什麼不是「運動心理學教科書」

渦流計劃的核心命題是：**技術形式是感知系統的輸出，不是輸入。** 心理層必須服從同一條規則，否則它只會變成一本貼進來的通用運動心理學手冊。

通用運動心理學問的是：「選手該有什麼感覺、該怎麼想。」
本框架問的是：**「選手說了什麼 → 由此判斷感知/控制狀態在哪一層。」**

因此心理層在本框架裡的定位**不是並排的第六個系統**，而是**感知學習能否發生的底層閘門**：

- 動機不足（amotivation）→ 選手不會自願把意識資源投向身體感覺 → 感知學習**事實上無法發生**（cluster 04）
- 恐懼（尤其「失去動作控制」的恐懼）→ 凍結或防禦性僵硬 → L0 呼吸感知無法建立（cluster 03）
- 壓力下的再投資（reinvestment）→ 把已自動化的感知-動作程序拆回顯性控制 → L6 被打回 L3–L4（cluster 02、07）

換句話說：**心理層不是「技術練好之後的加分項」，而是感知教學的前置條件。** 這是本框架對「運動心理學」最根本的重新定位。

## 1. 五條貫穿全部 8 份 dossier 的主軸

8 份 dossier 各自獨立蒐集，但放在一起會浮現五條反覆出現的主軸。這五條才是心理層真正的結構，dossier 只是它們的素材庫。

### 主軸 A — 注意力焦點的「第三類」：感覺水（cluster 01、06）

這是整個心理層**最吃重的單一發現**。

- Wulf 的經典二分：外部焦點（external focus, EF，注意動作對環境的效果）優於內部焦點（internal focus, IF，注意身體部位）。「把水推到身後」> 「手肘高提」。
- **但 2024 年 Bayesian meta（PMID 39480294）推翻了 EF 全面優越的結論**；Gottwald 2020 進一步顯示：在**本體感受主導**的任務上，一致性的 IF 反而更好。
- 渦流框架由此指出一個兩分法漏掉的類別：「**感覺水**」（感受掌心水壓、感受水流貼著前臂）既不是 Wulf 的 EF（不是注意外在效果），也不是典型 IF（不是注意身體部位幾何），而是**對感覺通道本身的主動引導 — 感知耦合焦點（perceptual coupling）**。

→ 這條主軸直接重寫了 Bridge 層的「指令層次設計」：身體運動語言（IF）/ 流體意圖語言（EF）/ 感知描述語言（第三類）是三層，不是兩層。
→ 它也預測了一個尚未被自我對話文獻研究的類別：**感知導向自我對話**（perception-oriented self-talk，cluster 06 的 🔴 原創假設）。

### 主軸 B — Flow ↔ Reinvestment 軸線，與「去再投資」（cluster 07、02）

心流與再投資是**同一條軸的兩端**，而這條軸的轉換機制正是 L5→L6 的核心。

| | Flow（心流） | Reinvestment（再投資） |
|---|---|---|
| 意識控制 | 極低，自動化接管 | 極高，顯性規則接管 |
| 感知語言 | 「身體自己知道」 | 「我不斷提醒自己要…」 |
| 觸發 | 挑戰-技能匹配 + 信任 | 壓力 + 對失敗的恐懼 |
| 對應 L 級 | L5–L6 | 被壓力打回 L3–L4 |

- 顯性學習（reinvestment 作為工具）在 **L1–L3 是必要的**，不是問題。
- **L5→L6 的關鍵轉換 = 成功「去再投資」（de-reinvestment）**：放掉顯性自我監控，信任已習得的隱性感知模式。L6 的「水在幫我」就是再投資降到最低、自動化達到最高的現象學報告。
- **Liao & Masters（2001）是這條軸的可操作介入證據**（DOI: 10.1080/02640410152006081 🟢）：用比喻式指導（原研究是**桌球**正手上旋的「直角三角形」拍路意象）取代顯性技術分解，壓力下表現更穩、累積的外顯規則更少。⚠️ 原研究是桌球非游泳；游泳的類比指導效果尚無第一手實證。
- 這條軸在 [〈隱性 vs 顯性學習〉](../implicit-explicit-learning/) 有完整展開：再投資的動作與決策分離、Liao & Masters 2001 的完整方法、Beilock 明確監控假說、IZOF／Hardy 壓力崩潰鏈。

### 主軸 C — EMG 悖論的心理橋（cluster 08，接 FUTURE_RESEARCH §0.5）

初學者過早的肌肉激活（Vaz 2016 PMID 26878097；Olstad 2017 DOI 10.1123/ijspp.2015-0703）有兩種解釋，互相競爭：

1. **焦慮驅動的過度控制（防禦性僵硬）** — 喚醒升高 → 肌肉張力前饋 → 干預感知通道
2. **預測性前饋（feedforward）** — 正常的運動預備，不是病理

cluster 08 的評估結論：**解釋 #1（焦慮過度控制）目前證據最強**（Langlet 等 2017 DOI 10.1016/j.neulet.2017.02.024，🟢×3）。

→ 同時 cluster 05 的意象研究提供解釋 #2 的橋：動覺意象使用 forward model（Kilteni 2018 PMID 29691389），把「預測性前饋」這條解釋連回可訓練的介入。

### 主軸 D — 動機氣候是感知探索的土壤（cluster 04）

- 感知學習的本質是**試錯探索**：停在「不確定的感覺」裡等身體調整。
- 表現氣候（performance climate）把錯誤解讀成能力不足 → 選手退回「有把握的舊感覺」，不敢探索新感覺 → **直接壓縮 L0–L6 賴以前進的探索空間**。
- 精熟氣候（mastery climate）把錯誤重構成訊息 → 提供感知進步的心理土壤。
- **關鍵推論（🔵）：本框架既有的「感知目標語言」（物理 / 感知目標 / 感知失敗的樣子 三層描述）本身就是精熟氣候工具** — 它讓選手把注意力指向「我現在感覺到什麼」而非「我比別人強不強」。應明確定位為動機設計工具，不只是教學描述工具。

### 主軸 E — 恐懼的特定簽名：失去動作控制（cluster 03）

- FWAQ（恐水量表）中，「**失去動作控制**」是最強的恐懼預測因子（Misimi 2020 PMID 32547447）— 不是泛泛的「怕水」，而是**對控制失效的恐懼**，本質上是一個感知/控制問題。
- 凍結反應是雙系統（Roelofs 2017 PMID 28242739）。
- → 這把恐懼直接接到 L0（呼吸/安全感知）這個閘門：在控制感建立前，上層感知無法堆疊。

### 主軸交互 D × E — 動機氣候調節恐懼的閘門效應（整合推導 🔵）

主軸 D（動機氣候）與主軸 E（失去控制的恐懼）在 dossier 04、03 各自被分開蒐集，但放在「感知優先」本體論下，它們不是兩條平行線，而是**同一個 L0 閘門上的乘法關係**。這是 8 份 dossier 與本總覽初版都漏看的二階整合——值得單獨記一條。

推導鏈：

1. 主軸 E 已確立：「失去動作控制」是最強的恐水預測因子（Misimi 2020 PMID 32547447），本質是控制失效的恐懼，卡在 L0。
2. 主軸 D 已確立：表現／自我涉入氣候（ego-involving climate）把錯誤解讀成能力不足，壓縮探索空間。
3. **交互推論（🔵）**：在表現氣候下，「失去控制」不再只是一個私下的感知掙扎，而被**外部評價放大成一次公開的能力判決**——失控 = 被看見的失敗 = 勝任威脅。於是同一份「失去控制」恐懼，在精熟氣候裡只是「再試一次的訊息」，在表現氣候裡卻被加乘成「我不行」的自我驗證。氣候不是恐懼的旁邊變項，而是**恐懼閘門的增益旋鈕**。

支持文獻（🟢）：自我涉入氣候與擔憂／焦慮的關聯，其強度取決於**知覺勝任感**——高勝任 + ego 氣候可能仍正向，**低勝任 + ego 氣候則負向效應最強**（Masters 泳者 Frontiers 2025，DOI 10.3389/fpsyg.2025.1574429 / PMC12098359；動機氣候-焦慮統合分析 DOI 10.3390/ejihpe14040064 / PMC11048888）。

**這條交互對「全光譜教學對象」特別關鍵**：低知覺勝任感正是**初學族群的共同起點**——成人初學（身體不在熟悉介質、社會性尷尬）、兒童初學（陌生環境 + 評價敏感）。對這兩群，L0 階段的氣候設計**不是加分項而是必要條件**：表現氣候會把本來就最高的「失去控制」恐懼再乘上勝任威脅，直接抬高 L0 閘門。對競技族群（青少年競技、兒童競技）則相反作用點——他們知覺勝任感較高，ego 氣候在 L4–L6 的主要傷害是壓縮**再探索**（停在有把握的舊感覺、不敢拆掉自動化去找新水感），而非卡死 L0。**同一條交互，在不同族群作用在不同 L 級**，不可一概而論。

→ 實務落點：對初學者，先用精熟氣候把 L0 的評價威脅卸掉，恐懼才有空間自然消退；既有的「感知目標語言」（主軸 D 第 4 點）正是現成工具——它把注意力從「我比別人差」轉回「我現在感覺到什麼」，等於同時關掉評價放大器。

## 2. 心理層 × L0–L6 對照

把 8 個 cluster 掛回感知框架，可見它們並非平均分布，而是**沿 L 級各有歸屬**：

| L 級 | 感知任務 | 主導心理 cluster | 核心心理機制 |
|------|---------|----------------|------------|
| **L0** 呼吸/安全 | 建立呼吸感知與控制感 | 03 恐懼 | 「失去控制」恐懼、凍結、CO₂ 敏感 vs 潛水反射 |
| **L1–L3** 顯性學習 | 局部感知 + 動作指令 | 01 注意力焦點、06 自我對話 | 顯性學習；再投資是**工具**；IST/外焦點指令 |
| **L4** 挑戰-技能接近 | 整合期 | 07 心流（短暫）、04 動機 | 偶發 flow；勝任需求滿足與 L 級晉升同構 |
| **L5–L6** 去再投資/水我合一 | 場感知、共振 | 07 心流、08 感知-生理 | de-reinvestment；「水在幫我」；內感受接管 |
| **全程貫穿** | — | 02 喚醒、04 動機、05 意象 | 喚醒調節、動機作為前置條件、意象作為前饋橋 |

**勝任需求 × L 級晉升的同構（🔵）**：SDT 的勝任需求（感受到「做得到」的進步感）與 L0–L6 的質性躍升天然對齊 — 每個 L 級里程碑都是一次真實的感知成就。L 級設計若執行得當，本身就在滿足勝任需求。

## 4. 渦流框架的原創貢獻（文獻空白，但具框架生成性）

以下五點是 8 份 dossier 反覆撞到、但現有文獻**沒有人正面研究**的命題。它們是本框架對運動心理學的潛在原創貢獻（目前 🔴 研究空白等級，但可作為未來實驗設計起點）：

1. **感知耦合焦點 = 注意力焦點的第三類**（cluster 01）。Wulf 的 EF/IF 二分漏掉「感覺水」這種對感覺通道本身的引導。
2. **感知導向自我對話 = 自我對話的第三類**（cluster 06）。Hatzigeorgiadis 的 IST/MST 二分漏掉「感受掌心水壓」這種既非技術指令亦非激勵語言的類型。
3. **「水在幫我」= L6/心流的可操作指標**（cluster 07）。可用「游者能否清楚說出手腳幾何」反向判斷：說得出 = 仍在 L4–L5 顯性控制；「就對了，不知道怎麼做到」= 接近 L6。
4. **感知目標語言 = 精熟氣候的動機工具**（cluster 04）。本框架既有的三層描述語言天然是 task-involving 語言。
5. **De-reinvestment 是 L5→L6 的轉換機制**（cluster 02、07）。類比學習（Liao & Masters 2001，**桌球**實證；游泳應用為外推）是已知的隱性學習介入手段。

> 第 1、2 點共享同一個更深的結構：**Wulf 焦點 × Hatzigeorgiadis 自我對話 × 渦流指令層次** 三者可對齊成一張表（見 cluster 06 §連結），而渦流的「感知描述」維度比兩者的既有二分都更細。
