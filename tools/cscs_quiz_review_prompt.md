## 第二步：逐題審，每題問這七個問題

第 1–4 問對**每一題的兩個干擾項**逐個問，第 5–7 問對整題問：

1. **一個讀完本章、但讀得不夠細的人，會不會選它？**
   會 → 合格。不會 → 不合格，重寫。
   不合格的樣子：`bones shorten to push joints`（骨頭會縮短）、`tendons contract`（肌腱會收縮）、
   `竇房結因長期訓練而永久退化`、`副交感神經完全失去作用`。這些不需要讀過書就知道是假的，
   它們不是干擾項，是墊檔。
   合格的樣子：**把相鄰概念的正確敘述錯置到這一題**——I 帶／A 帶對調、把鈣釋放當能量來源、
   把 GTO 的抑制方向講成興奮。考生真的會選。

2. **這個選項裡的術語是真的嗎？`why_wrong` 裡的機制也是真的嗎？**
   `γ-fiber hypertrophy`（沒有這種東西）這類自己拼出來的詞一律重寫。
   只能用本章 `__CHID__.yaml` 裡出現過的術語，或該領域公認的標準術語。
   **`why_wrong` 受同一條約束**：ch03 有一則錯因寫「CP 復元需完整有氧週期」——
   「有氧週期」不是術語，而且源檔說 ATP 與 CP 的再合成都主要靠有氧代謝，
   這條錯因等於一邊編詞一邊講反了機制。錯因裡的每個因果句都要能在源檔找到依據。

   另一種變形是**把源檔的正確敘述改幾個數字再放進選項**：源檔寫「超極量（>100%
   VO₂max）的短暫間歇」，ch03 的干擾項寫成「>90% VO₂max、5 分鐘的高強度間歇」，
   錯因還稱它是「另一條 EPOC 最大化路徑」——半真半假比全錯更糟，考生查書會對不上。
   干擾項可以是錯的，但不能把書上的話改寫成一個書上沒有的說法。

   **錯因把機制講反**是 ch04 最常見的一類：`cortisol.i03` 的錯因寫「高皮質醇會抑制而非
   刺激兒茶酚胺釋放」——實際上皮質醇是誘導 PNMT、促進腎上腺素合成的，方向整個相反；
   `catecholamines.i08` 的錯因寫「臨用臨合成符合多肽荷爾蒙的模式」，而源檔講的正是
   嗜鉻細胞**預先合成並囤積於囊泡**。錯因只要含一句因果，就回源檔把那句對一次。

   **錯因自己發明數字或門檻**同樣要抓：`cortisol.i05` 的錯因寫「1500 nmol/L 是內分泌
   專科的病理警訊」，但源檔全章只有 800 nmol/L 這一條線。源檔沒有的數字，錯因裡不准出現。

3. **正解真的是唯一正確的嗎？而且它有在回答問題嗎？**
   如果某個干擾項在某種讀法下也成立，把題幹的限定詞收緊，或換掉那個干擾項。
   另一個相反的毛病是**正解只是把題幹換句話說**：題幹問「肌腱附著點比常人遠，主要的取捨是什麼」，
   正解寫 `tendon insertion`——等於把題幹的主詞抄回來當答案，不必懂就選得到。
   正解要寫出那個取捨本身（`more torque, but a smaller joint sweep`），不是指回題幹講過的東西。

4. **三個選項是不是在講同一個層次的事？**
   問機制就三個都是機制，問構造就三個都是構造。數字題三個必須是同一個量的三個數值——
   同單位、同被測對象，只有數值不同。
   ch03 的反例：題幹問「哪個功休比最適合磷酸原系統」，正解是功休比，兩個干擾項卻是
   `Half-minute maximal sets, brief rest, accumulate lactate` 與
   `Long easy jogs develop mitochondrial enzymes`——訓練描述不是比值，考生不必知道
   1:12–1:20 也答得出來。改成 `1:18, six-second sprints` / `1:3, twenty-second hard bouts` /
   `1:1, five-minute easy runs`，三個都是比值，才逼考生真的記得 Table 3.6 的三段區間。

   還要**回頭比對這一章已經出過的題**：ch03 的 `oxidative.i03` 與 `glycolysis.i04` 正解
   撞同一個概念（hexokinase 每分子游離葡萄糖耗 1 ATP），題幹不同但考的是同一件事。
   閘只擋同一個 item 底下的重複題幹，擋不到跨 item 的概念重複。撞到就從該 item 的
   其他知識點另起一題（`oxidative.i03` 改考「氧化磷酸化佔 >90% 的 ATP 合成」）。
   最常見的破口是**只有正解是專業術語，兩個干擾項是白話描述**：
   `isometric` / `lifting up` / `lowering down` 這一組，考生不必知道等長是什麼，
   光看哪個是術語就選得到。三個都要是術語層級（`concentric` / `eccentric` / `isometric`
   本來就是本章並列的三個名詞），或三個都是白話描述，不能混。

   ch04 的跨 item 撞概念有一個更隱蔽的版本：`testosterone.i06` 與 `program-design.i01`
   這**兩個源條目本身的 `a` 清單一字不差**，照各自的 item 出題必然撞正解。
   遇到內容重疊的兩個 item，第二題要從該 item 的 `detail` 或 `numbers` 另找角度，
   不能照 `a` 再寫一次。同理，兩題的正解各自落在「訓練量」與「休息時間」才算分開，
   一題的正解寫成「多組數＋短休息」就等於把另一題也答掉了。

5. **兩個干擾項的錯因是不是在講同一件事？**
   `testosterone.i08` 原本兩條錯因都在說「末端還在照訊號運作」，只是換句話說。
   兩個干擾項代表兩種不同的思考錯誤，錯因也必須是兩套推理。

6. **選項是不是為了過長度閘而被壓成半通不通的句子？**
   `cortisol.i04` 原本三個選項是 `single spike alone ends gain`、
   `the hormone quit braking entirely`，錯因寫 `Quashes phase swap`——
   母語者讀不懂，這不是簡潔而是壞掉。英文選項抓 24–32 字元、錯因寫成完整句子；
   長度閘過不了就**改題幹的提問角度**讓選項自然變短，不要把句子剁碎。

7. **題幹有沒有依賴別題？**
   題庫是打散抽題的，`program-design.i01.q2` 原本寫「最能配合**上述處方**」——
   考生看不到那個「上述」。每一題都必須自足，不准出現上述／前題／承上這類指涉。

## 第三步：改

- **只能改 `options` 底下的 `text` 與 `why_wrong`。**
  `id` / `item` / `dco` / `lang` / `cognitive` / `locator` 一個字都不准動。
- **`stem` 只有三種情況可以動**：第二步的第 3 點（正解只是把題幹換句話說）、
  第 6 點（選項被長度閘壓壞、要靠換提問角度救）、第 7 點（題幹指涉別題）。
  改的時候只准動提問句（`Which factor primarily determines...?`
  → `What is the primary trade-off...?`）或拿掉指涉詞，情境敘述與比較限定詞
  （most／primary／最主要）一律保留。其他任何理由都不准碰 `stem`。
- 改掉一個 `text` 之後，**它的 `why_wrong` 必須跟著重寫**——錯因要說「考生犯了哪個思考錯誤」，
  不是把選項換句話說。
- 改完三個選項要維持：語法平行、長度相近（最長不超過最短的 1.5 倍）、正解不得是最長的那個、
  不准用縮寫或希臘字母把某一個縮短（`ν`、`ΔP` 都會被擋；`α-motor unit` 這種本來就是術語的可以）。
- 中文不可出現簡體字。
