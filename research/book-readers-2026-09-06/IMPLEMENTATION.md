## 設計

以現代中文教科書旁註版面為文化／物件參照；米白紙面 #faf8f2、墨色 #202c30、藍綠連結 #225c61。正文 Georgia / Noto Serif TC / PMingLiU / serif，工具 Arial / Noto Sans TC / Microsoft JhengHei / sans-serif；系統字型保底，不依賴下載。正文 20px、36px 行距、36em 最大行寬；規律的正文＋目次網格，寬鬆段落、緊密來源註。手機單欄，圖不裝飾、只解釋概念。

## 品質邊界與恢復

章頁採連續正文，主論述不藏在卡片或收合區。每章描述與內容由 canonical Markdown 擁有，章序／主題／術語由 data/reading 擁有，導航與搜尋依資料生成。不同書的說法保留各自上下文，不硬合成共同結論。source-audit.json 紀錄來源可取得、可讀程度與實際核對範圍；成功建置僅表示結構通過。

原頁與原文只由本機唯讀服務回應。服務無寫入端点、無排程、無登入；關機後重跑啟動入口即可恢復，沒有補跑工作。localStorage 僅保存非必要閱讀偏好，拒絕儲存或毀損時退回預設。所有正文在 JS 關閉時仍可讀。

空資料、最大章、缺來源、錯誤 ID、特殊搜尋文字、來源 URL 路徑穿越、localStorage 毀損與重啟各驗證其適用行為。建置採單一寫入，HTTP 服務只讀；並行請求測原頁互不混淆。新內容／樣式獨立，可移除本次新增檔回復；既有頁不做順手修正。
