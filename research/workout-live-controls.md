## 4–5. 風險、偵測與復原
- 時鐘／共享狀態：UI 事件與 interval 必須原子修改；表單開啟先暫停，沒有背景非同步重建。測試開表單後快轉、取消、連按跳過、暫停時跳過與動態出發間隔。復原快照包含相互參照的課表、序列、調整 Map、紀錄與兩個 elapsed 值；還原後重設時間原點。
- 空／大量／中途：禁止刪掉正在游的趟、限制組數 1–20、趟數 1–99；分段至少保留已到達的段。測試空課表、20×99、最後一趟誤跳、組間／項目間休息修改、完成後撤銷。失敗可撤銷最近 10 次操作，已完成紀錄不重建。
- 遷移：v3 優先，其次合併 studio/v2，完全相同課表去重；同 drill ID 不同內容重映射。兩個舊 key 都不改，舊分頁寫入仍隔離；新分頁沿用現有最後寫入者機制。測試並行舊分頁、重整、PB 清空、儲存 quota 失敗。若部署需回退，可還原功能 commit；舊資料仍在。
- 不可信輸入：live 表單整數／有限時間／列舉／長度驗證；保留未變更的配速規則；HTML 以 esc/textContent 呈現。測 malformed、0、負數、Infinity、非法分秒、含 HTML 備註。不涉及 SQL/SSH/LLM 回應；命令無插入使用者資料。
- 進度一致性：rest 也携帶 s/r/g，重建後以坐標切開已完成與未完成步驟；前綴保留，時鐘／出發間隔參照點保留；若 rest 被移除，下一步從 0 暫停。測 set/rest/sendoff/broken/progression 與快調秒數交互；結果複製包含跳過及修改紀錄。
- 外部發布：舊試用網址與分享 hash 需實測；手機 320/390 與桌面操作不得溢出。部署失敗不宣稱上線；修復或還原同一功能 commit。
