# 個人／團體模式與逐人成績配速（2026-10-09）

使用者希望個人介面保持乾淨，但團體也能輸入成績，推算主課目標、休息與包干。本輪沿明確需求實作，保留手動調整與既有 HIIT。

- [x] 預設個人模式；團體有獨立內容區，隱藏個人側欄與單人計時入口，返回時保留本次輸入。
- [x] 個人／團體共用既有 canonical 配速與七種主課計算；每位團員以獨立成績物件計算，不借用個人 PB，不改全域 PB／CSS cache。
- [x] 團體可選主課、泳式與份量，逐人輸入成績或手動目標。缺資料明示，不拿估時當目標；換池長／泳式／器材條件重新確認參照。
- [x] 支援固定休息、共同包干及原分批；完整組數／趟數與組間休息。區分建議休息及共同包干後的實際休息；固定休息的後續出發表是依目標游速的估算。
- [x] 驗證逐人推算與個人一致、資料隔離、缺漏／非法成績、組間時間、分批、前後切換、複製、手機與既有六套回歸。
- [ ] 22 specs／121 舊網址、畫面確認、部署與正式站驗證。

範圍：workout.js 的配速參照與唯讀介面、workout-lane.js／partial、studio 模式導覽、既有樣式與測試。沒有多人即時計時、持久保存名單、AI、canonical 處方更新或背景排程。

主要風險：成績誤用他人資料／泳式／池長；已算秒數在成績或主課變更後殘留；組間與換批等待被漏算；切換隱藏區影響推薦加入與深連結；固定休息被誤認為固定時鐘出發。以獨立參照、來源標示與失效處理、逐人時間恆等式、實際瀏覽器切換及說明驗證。不新增網路資料傳送；名單與成績重新整理清空。若需撤回，revert 功能 commit 再部署，既有儲存格式不需遷移。

## 實作與驗證

- `[manual]` 共用配速：`workout.js` 的讀取、CSS、組型與目標計算接受獨立成績參照；`groupRecommendation()` 清理與檢查成績後才推算，支援百分秒。缺資料的團體組型不呼叫個人估時 fallback。組型與生理配速規則沒有另立一份 canonical。
- `[manual]` 介面與排程：`workout-studio.js` 控制兩種模式與深連結；`workout-lane.js` 維持純排程函式，加上完整組數與固定休息。每組結束等人到齊，休息與整理取較大者；下一組沿原順序錯開出發。每人實際組間休息含等待，最後到牆不加多餘趟間休息。
- 具體驗收：200／400 m 為 150／320 秒與 180／380 秒時，100 m 閾值目標分別為 85／100 秒。共同 120 秒週期給休息 35／20 秒；固定休 20 秒則預估週期 105／120 秒。2 組 × 3 趟、組間到齊休 60 秒、5 秒錯開，最後一人 12:30 到牆、12:35 可換段。
- `tools/test_workout_group.cjs`：七種目的、四泳式、獨立成績／無資料／非法值、手動與推算混用、整組帶入、條件變更失效、模式保留與重整清空、複製及 320／390／1440 px。
- `tools/test_workout_lane.cjs`：既有包干／分批／休息交集，加上多組、固定休息、逐趟輪流的組間等待及一趟多組邊界。既有 studio／goals／timer／live／audio 回歸皆通過；沒有新增多人即時計時。
- MAP 已更新本輪入口；全域 map freshness 稽核仍列出先前未列入地圖的其他檔案，與本輪範圍無關。
