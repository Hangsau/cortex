# 無賽期主課推薦（2026-10-06）

使用者修正方向：USRPT 不必另外做一份課表，也不必優先做完整執行模式；需要沒有特定賽事的人也能按訓練目的選推薦主課。本文件取代 2026-10-05 研究筆記的「下一版先做 USRPT」優先順序。

## 1. 完成狀態

工作台能在不填賽事日期時選擇主課目的、泳式與參考份量，預覽後加入目前課表或另建課表，既有賽期推薦仍可使用。

## 2. 範圍與邏輯分布

- `next/layouts/_partials/vortex/workout.html`：新入口、表單；將 canonical `energy_targets.intents` 傳給前端，標籤和目的沿用資料。
- `next/assets/js/workout.js`：沿用 `setBuilders()`、`targetOf()`、`addMain()`、既有存檔；補穩定有氧與乳酸生成組型。`refresh()` 在 PB 改變時重算預覽；`initGoals()` 管理選單。`weekPlan()` 共用既有 builders，但沒有更動其預設排法。
- `next/assets/js/workout-studio.js`：推薦區放在成績與建議最前方，排課頁有直接入口；明確處理新增後回到排課，即使前後項目數相同也切換。
- `next/assets/css/workout.css` / `workout-studio.css`：表單與預覽，沿用設計參數。
- `next/content/vortex/workout.md`：頁面說明。
- `tools/test_workout_goals.cjs`：瀏覽器整合驗收；三套既有瀏覽器測試保持不變。
- Hugo 產物／fingerprint 資源經 GitHub Pages 發布；HANDOFF 記錄版本與驗收。

不增加 USRPT 計時模式、PB 持久化、主課生成以外的暖身／drill 自動編排、AI API、雲端同步或 canonical 生理處方修訂。上輪找到的文獻書目與退出規則問題保留待修，新的賽速預覽不用那段不完整 exit 簡寫充當自動規則。

使用者是電腦／手機上的同一靜態網站訪客；頁面載入後在瀏覽器運算，不新增定時任務或伺服器。休眠、離線與恢復不觸發背景推薦；再開頁重新選擇即可。既有日期推算仍用當地日期。PB 每次開頁清空；生成後課表沿用瀏覽器存檔，沒有更改計時中斷恢復能力。

## 3. 執行路徑

1. 核對 builders／配速／週計畫／studio 掛載與資料來源。缺少資料時不另造生理公式。
2. 以同一套主課列格式加入目的推薦；選單選擇只留記憶體，不新增存檔 migration。
3. 本機 Hugo 預覽、瀏覽器測試與 22 項網站檢查、121 舊網址映射；任何驗收失敗先修正，未通過不推送。
4. 提交功能、測試與設計記錄；推送既有 `hugo-source`。CI 完成後以公開頁驗證新入口，更新 HANDOFF。

## 4. 風險

- 共用組型修改可能波及賽期推薦：只新增 builders 與可選參考距離，原參數缺省路徑不變。
- 沒有 PB／不合法 PB 可能被當成有效配速：目標計算仍走 `targetOf()`；預覽顯示待補，允許組型加入，不能捏造秒數。
- 減量或多組可能切掉恢復：精簡只減組數／趟數；新純速範例的組間休息等於每趟完整休息。穩定有氧沒有專屬休息公式，範例保留明示的休息，避免 `autoRest()` 歸零。
- 狀態／相容性：產生列符合原 `ROW_DEF`，沒有新分享／存檔格式。單頁同步事件無新競態；多正式分頁仍為既有最後寫入者行為，不聲稱新增跨分頁同步。
- 空、部分與大量輸入：零成績可以產組；缺失特定泳式成績不借別式；份量選擇有限，既有大課表和中途中止由原測試覆蓋。
- 外部輸入與注入：purpose／stroke／size／event 以允許集合驗證；預覽的資料文字經 `esc()`；沒有 LLM 輸入、SQL、SSH 或新增 shell 拼接。
- 狀態生產與消費：沒有新計時狀態；列加入後由相同編輯器、摘要、分享與 timer 讀取。新增 UI 事件只負責返回排課。

## 5. 偵測與恢復

- 新測試驗無賽期七類、缺 PB、七種數值、獨立泳式、參考距離切換、精簡與原量的休息、另建不覆蓋、PB 清空、非法選項、原週計畫、320／390／1440 寬度。
- 既有 timer／studio／live 三套驗證儲存、舊版合併、分享、撤銷、途中編輯、空和大量課表；沒有改存檔 schema，不需資料 migration 或刪除既有 key。
- Hugo／瀏覽器若被執行環境阻擋，使用已授權本機驗收的正常執行環境，不改測試斷言躲過失敗。
- 發布失敗時先檢查該 commit 的 CI 記錄；只修正造成失敗的變更。需要撤回則 revert 本次功能 commit 並重跑檢查，保留現有 `cortex-swim-v3` 和課表，不刪除使用者資料。

共用既有生成器比新增另一套能量系統／USRPT 編輯器簡單。功能限於目的推薦與進入方式，不擴成完整自動教練。
