# W7：集合清單頁（含篩選）

本單**整個重寫** `next/layouts/_partials/vortex/list.html`，新建 `next/assets/css/list.css` 與 `next/assets/js/filter.js`（兩者只在清單頁載入）。只准動這三個檔。
清單類型在 `.Params.list_type`（move、drill、tech、error、problem、injury、level、psy）；psy 清單要同時列出 psy 與 psyc（psyc 縮排在其主題下）。

## 版面（`<article class="page page--wide list" data-list>`）
1. h1 頁標題；一行 muted：「共 N 條」
2. **篩選列**（`<div class="filters" role="group" aria-label="篩選">`），只在該類型需要時輸出：
   - 泳式：move、drill、tech、error、problem、level 有；按鈕「全部」＋ 各泳式中文名（只列實際出現的泳式）
   - 類別：drill、tech、error、problem、injury 有；按鈕「全部」＋ 該類型 `categories` 中實際出現的類別（name_zh）
   - drill 另有「器材」：「全部」「不需器材」「需要器材」
   - 按鈕是 `<button type="button" aria-pressed="true|false" data-filter="<維度>" data-value="<值>">`
3. **清單** `<ol class="items">`：每項 `<li data-stroke="…" data-category="…" data-equip="none|some">`，內含連結（標題粗體）＋ muted 的 hook；依 stroke 順序（free, back, breast, fly, udk, starts-turns）再依 id 排序。drill 的 data-stroke 放所有泳式 key，以空白分隔。
4. 篩選後若無結果，顯示 `<p class="empty" hidden>沒有符合的項目</p>` 並取消 hidden

## filter.js
- 不用任何函式庫；`defer` 載入
- 同一維度單選（按了就把該維度其他按鈕 aria-pressed 設 false），不同維度取交集
- 以 `li.hidden = true/false` 切換；CSS 需寫 `.items li[hidden] { display: none; }`（作者樣式若設了 display 會蓋掉 UA 的 hidden，務必寫這條）
- 更新「共 N 條」為目前可見數
- 篩選狀態寫進網址 query（如 `?stroke=free&category=breathing`），載入時讀回
- 沒有 JS 時全部項目可見（預設不加 hidden）

## list.css 要點
- 篩選按鈕：`min-height: var(--tap)`、1px `--rule` 邊框、圓角 ≤4px、背景 `--paper`；`aria-pressed="true"` 時背景 `--series`、字 `--paper`
- 篩選列可換行；手機可水平捲動但頁面本身不可出現水平捲動（篩選列本身 `overflow-x: auto`）
- 清單項 `min-height: var(--tap)`，下 1px `--rule`，無框
