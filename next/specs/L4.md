# L4：大腦喜歡這樣學（MNFL）與 Uncommon Sense Teaching（UST）

本單不涉及 Vortex；共用背景中「設計規範」「內容呈現鐵則」照樣適用。

## 已存在、不准修改的東西
- 書房共用版型（Claude 寫）：`next/layouts/_partials/library/{dispatch,series-of,rail,series-home,reader-chapter,reader-topics}.html`、`next/assets/css/{library,shell,tokens}.css`。
- 分派：頁面 params 有 `role: X` 就渲染 `next/layouts/_partials/library/X.html`，傳入 `(dict "page" <頁面> "series" <系列 dict>)`。**系列首頁（路徑等於系列 path）自動用 series-home，你只需要建 `_index.md`。**
- 系列資料 `hugo.Data.library.series`：`mnfl`（path `library/mind-for-numbers/`，20 個 entries，每個 `{id,title,desc,path,group,group_name}`）、`ust`（path `library/uncommon-sense-teaching/`，10 個 chapters `{n,id,title,desc,path}`、18 個 entries）。頁面網址必須和這些 path 完全一致。
- 可直接沿用的 class（已在 library.css）：`lib-chapter`、`lc-head`、`lc-lead`、`lc-body`、`lc-pager`（含 `a.lc-prev`／`a.lc-next`）、`lib-entry`、`le-block`、`kicker`、`read`、`muted`。

## 資料（唯讀）
- `data/mnfl/techniques.yaml`：`themes[{id, name, desc, techniques[{id, name, essence, why, how[]}]}]`（why 是一段文字，how 是字串清單）
- `data/ust/chapters.yaml`：`chapters[{num, title, subtitle, claim, keys[], try[]}]`
- `data/ust/strategies.yaml`：`categories[{id, name, color}]`（**不准使用 color**，顏色一律用 tokens）、`strategies[{id, name, category, chapter, essence, how[]}]`

## content adapter
- MNFL：每個 technique 一頁，path＝technique id；title＝name；params `{role: "mnfl-technique", technique_id, theme_id}`；description＝essence
- UST：10 個章節頁 path `ch01`…`ch10`；title＝title；params `{role: "ust-chapter", chapter_no}`；description＝subtitle。18 個策略頁 path `strategies/<id>`；title＝name；params `{role: "ust-strategy", strategy_id}`；description＝essence。另加一個 section 頁 path `strategies`，title「課堂策略」，params `{role: "ust-strategies"}`——**這一頁不另寫 partial**：在 `ust-strategy.html` 開頭判斷 `.page.Params.role` 為 `ust-strategies` 時輸出策略總表（見下），所以 content adapter 對它也設 role `ust-strategy` 並加 param `index: true`。

## 條目頁共同結構（三個 partial 都照這個骨架；先 `resources.Get` 載入 `css/library.css` 與 `css/entry.css`）
```html
<article class="lib-chapter lib-entry">
  <header class="lc-head">
    <p class="kicker">系列名 · 分組名</p>
    <h1>標題</h1>
    <p class="lc-lead">一句話（essence／subtitle）</p>
  </header>
  <section class="le-block"><h2>區塊標題</h2> … </section>   ← 可多個，無內容就整塊不輸出
  <nav class="le-siblings"> … </nav>
</article>
```

### mnfl-technique.html
- kicker「大腦喜歡這樣學 · <theme name>」
- `le-block`「為什麼有效」：why（markdownify，外包 `<div class="read">`）
- `le-block`「怎麼做」：how → `<ol class="le-steps">`
- `le-siblings`：「同一主題的其他技法」＋ 同 theme 其他 technique 的連結（標題＋ essence 一行 muted）；最後一行連回系列首頁「看全部 20 個技法 →」（數字實算）

### ust-chapter.html
- kicker「大腦喜歡這樣學・強效教學版 · 第 N 章」
- `lc-lead`：subtitle
- `le-block`「核心主張」：claim（`<p class="read le-claim">`）
- `le-block`「重點」：keys → `<ul class="le-points">`（markdownify）
- `le-block`「課堂試試看」：try → `<ul class="le-points">`
- `le-block`「本章策略」：strategies 中 chapter＝本章者，每個連到策略頁（標題＋ essence）
- `lc-pager`：上一章／下一章（`<span class="muted">上一章</span><span>N　標題</span>`）

### ust-strategy.html
- 若 `.page.Params.index` 為 true：輸出 `<article class="lib-series">`，`<header class="ls-hero">` 內 kicker「大腦喜歡這樣學・強效教學版」、`<h1 class="ls-title">課堂策略</h1>`、`<p class="ls-lead">18 個可以直接帶進課堂的策略，依用途分組。</p>`（數字實算）；再依 categories 順序分組：`<h3 class="ls-part">分類名</h3><div class="ls-entries">` 每個策略 `<a class="ls-entry" href><span class="ls-entry-t">名稱</span><span class="ls-entry-d">essence</span></a>`
- 否則（單一策略頁）：kicker「大腦喜歡這樣學・強效教學版 · <分類名>」；`le-block`「怎麼做」：how → `<ol class="le-steps">`；`le-block`「出自」：連到第 N 章頁面「第 N 章　章名」；`le-siblings`：同分類其他策略連結；最後一行連到 `strategies/` 總表

## entry.css（只用 tokens；不准卡片框、陰影、圓角 > 4px）
- `.le-steps`：編號清單，每項上方 1px `--rule`、上下 `var(--s2)`、襯線、行高 1.8；編號用 `--series` 色粗體（用 CSS counter，`list-style: none`）
- `.le-points li`：襯線、行高 1.8、`margin-bottom: var(--s2)`
- `.le-claim`：`--fs-l`、左側 4px `--series` 規則線、`padding-left: var(--s3)`
- `.le-siblings`：`margin-top: var(--s6)`、上方 2px `--ink` 規則線、`padding-top: var(--s2)`；內部連結清單每項上方 1px `--rule`、`min-height: var(--tap)`，標題 `--ink` 粗體襯線、hover 變 `--series`
