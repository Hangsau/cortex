## 產出檔（只准建立這些）

## _content.gotmpl（Hugo content adapter，路徑相對於 `next/content/vortex/`）
用 `$.AddPage` 產生：
1. **集合清單頁**（kind `section`）8 個：path `drills`、`tech`、`errors`、`problems`、`injuries`、`levels`、`mind`、`moves`；title 依序「練習」「技術分析」「教學誤區」「找問題」「運動傷害」「水感發展級別」「心理層」「全部動作」；params `{role: "list", list_type: <對應 type，mind 用 "psy">}`
2. **泳式樞紐頁**（kind `page`）6 個：path＝泳式 key（`free` 等），title＝中文泳式名，params `{role: "stroke", stroke: <key>}`
3. **知識點頁**（kind `page`）每個 unit 一頁：path＝unit.path 去掉開頭 `vortex/` 與結尾 `/`；title＝unit.title；params `{role: "unit", unit_id: <id>, unit_type: <type>}`；若 hook 非空，把 hook 當 `description`（可用 params.description 或頁面欄位，擇 Hugo 支援者）

## 版型分派
`next/layouts/vortex/page.html` 與 `section.html` 都是：
```
{{ define "main" }}
{{ $role := .Params.role | default "unit" }}
{{ if eq $role "home" }}{{ partial "vortex/home.html" . }}
{{ else if eq $role "list" }}{{ partial "vortex/list.html" . }}
{{ else if eq $role "stroke" }}{{ partial "vortex/stroke.html" . }}
{{ else }}{{ partial "vortex/unit.html" . }}{{ end }}
{{ end }}
```
占位 partial：各自輸出 `<div class="page"><h1>{{ .Title }}</h1><p class="muted">（版型建置中：role 名稱）</p></div>`。

請實際建置確認 `next/layouts/vortex/page.html` 確實套用到 `vortex/drills/fr1/` 這種深層頁（看輸出 HTML 有占位字串）；若 Hugo 沒套用，調整檔案位置直到套用，並在最後回報中寫明實際位置。
