# W8：Vortex 首頁

本單**整個重寫** `next/layouts/_partials/vortex/home.html`，新建 `next/assets/css/home.css`（只在 Vortex 首頁載入）。只准動這兩個檔。
目標讀者是**任何人**：教練、選手、家長、初學者、路過的人。不問身分、不分流；用真實內容讓人想點下去。

## 版面（`<article class="page page--wide vx-home">`）
1. **開頭**：h1「水感」；`.read` 導言（照抄以下文字）：
   「技術是水感的輸出，不是要照抄的動作。這裡把六種泳式拆成一個個動作，每個動作都接到怎麼練、常見的錯誤想法、背後的物理，以及練不起來時該看哪裡。從任何一頁開始都可以，每一頁都會告訴你接著看什麼。」
2. **六種泳式**（h2「六種泳式」）：6 列，每列：泳式名連結（粗體、`--fs-l`）＋ premise 的第一句（到第一個「。」為止）＋ muted「N 個動作 · N 個練習 · N 條誤區」（數字從 units 實算）
3. **10 個反直覺的誤區**（h2）：從 type=error 中挑 10 條：依泳式順序 free, back, breast, fly, udk, starts-turns 輪流各取一條（每式依 id 順序取下一條），取滿 10 條為止。每條：標題連結（粗體）＋ 下一行「很多人以為：」＋ misconception 前 50 字（超過加…）
4. **水感怎麼一級一級長出來**（h2）：以自由式 level（free.L0 … free.L6）為例，每級一列：級別代號（L0…）＋ name_zh 連結 ＋ tagline；最後一行 muted「仰式、蛙式、蝶式的級別見各泳式頁」
5. **全部內容**（h2）：一列一個集合連結，附實算數量：練習、技術分析、教學誤區、找問題、運動傷害、水感發展級別、心理層、全部動作（連到 W4 的 8 個清單頁）

## home.css 要點
- 開頭 h1 字級 `--fs-xl`，與導言間距 `--s2`；導言用 `--fs-l`
- 各區塊間距 `--s6`；列之間 1px `--rule`；列最小高度 `var(--tap)`
- 不准卡片框、陰影、大色塊；強調只用 `--series`（連結與級別代號）
