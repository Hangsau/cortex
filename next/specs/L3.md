# L3：CSCS（肌力與體能訓練精要）的章節頁與概念索引

本單不涉及 Vortex；共用背景中「設計規範」「內容呈現鐵則」照樣適用。

## 已存在、不准修改的東西
- 書房共用版型由 Claude 寫好：`next/layouts/_partials/library/{dispatch,series-of,rail,series-home,reader-chapter,reader-topics}.html`、`next/assets/css/{library,shell,tokens}.css`。
- 分派規則（`dispatch.html`）：頁面 front matter／params 有 `role: X` 就渲染 `next/layouts/_partials/library/X.html`，傳入 `(dict "page" <頁面> "series" <系列 dict>)`。系列首頁（路徑等於系列 path）自動用 series-home，不需要你做。
- 左側目錄 `rail.html`：若目前頁面 params 有 `sections`（清單，每項 `{id, title}`），會在目前章節底下列出這些小節錨點。
- 系列資料 `hugo.Data.library`（`next/data/library.json`）：cscs 系列的 path 是 `library/essentials-of-strength-training/`，chapters 已含 24 章的 n／id（`chNN`）／title／path。

## 產出檔（只准建立這些）
- `next/content/library/essentials-of-strength-training/_index.md`：front matter 只有 `title: 肌力與體能訓練精要`
- `next/content/library/essentials-of-strength-training/_content.gotmpl`（Hugo content adapter）
- `next/layouts/_partials/library/cscs-chapter.html`
- `next/layouts/_partials/library/cscs-concepts.html`
- `next/assets/css/cscs.css`
- `next/assets/js/cscs.js`

## 資料（唯讀，`data/cscs/`）
- `chNN.yaml`（ch01–ch24）：`{id, weight, title, topics[{id, title, desc, tag, items[...]}], cards[...]}`
  - item：`id`（如 `ch05.cardiovascular-adaptations.i02`）、`q`（標題）、`a`（字串清單）、`detail`（字串）、`terms`（指 `_terms.yaml` 的 key）、`numbers`（`[{v, unit, of}]`）、`concepts`（指 `_concepts.yaml` 的 key）、`related`（其他 item 的 id，可能跨章）、`locator`（原書出處）
- `_terms.yaml`：map，key → `{en, zh, note}`
- `_concepts.yaml`：map，key → `{zh, desc, group, order}`
- Hugo 內讀法：`index hugo.Data.cscs "ch05"`、`index hugo.Data.cscs "_terms"`、`index hugo.Data.cscs "_concepts"`

## content adapter
用 `$.AddPage` 產生：
1. 24 個章節頁：path `ch01`…`ch24`；title＝該章 yaml 的 title；params `{role: "cscs-chapter", chapter_key: "chNN", chapter_no: N, sections: [ {id: <topic id>, title: <topic title>} … ]}`；description＝前三個 topic title 以「、」串接
2. 概念索引：path `concepts`；title「概念索引」；params `{role: "cscs-concepts"}`

## cscs-chapter.html（`<article class="lib-chapter ck-chapter">`，先 `resources.Get` 載入 `css/library.css`、`css/cscs.css`，頁尾載入 `js/cscs.js`（defer））
1. `<header class="lc-head">`：`<p class="kicker">肌力與體能訓練精要 · 第 N 章</p>`、`<h1>`、`<p class="lc-lead">` 放「本章 K 個主題、M 條知識單位」（實算）
2. 工具列 `<div class="ck-toolbar">`：一個按鈕 `<button type="button" class="ck-quiz-toggle" aria-pressed="false">遮住答案自測</button>` ＋ 說明文字 `<span class="muted">按下後答案先收起，點一下題目才顯示</span>`
3. 每個 topic：`<section class="ck-topic" id="<topic id>">`，`<h2>` topic title，有 desc 就接 `<p class="ck-topic-desc">`
4. 每個 item：`<section class="ck-item" id="<item id>">`（id 必須完全等於 item id，跨章連結靠它）
   - `<h3 class="ck-q">` q
   - `<ul class="ck-a">` 每條 a 一個 `<li>`（markdownify）
   - numbers（有才輸出）：`<p class="ck-numbers">` 每筆「of：v unit」，以「；」分隔，數字 `<b>`
   - terms（有才輸出，**常駐可見不可收合**）：`<p class="ck-terms">` 每個 term「zh <span lang="en">en</span>」，查不到 key 就印 key 本身
   - detail（有才輸出）：`<details class="ck-detail"><summary>為什麼／代表什麼</summary><div class="read">…</div></details>`
   - concepts（有才輸出）：`<p class="ck-concepts">` 每個概念一個連結到 `concepts/#<concept key>`，文字用概念 zh
   - related（有才輸出）：`<p class="ck-related">相關：` 每個 id 連到它所在章節頁的 `#<id>`（章號取 id 的前綴 `chNN`），連結文字是該 item 的 q；同章就只寫 `#<id>`；找不到的 id 印出 id 本身
   - locator（有才輸出）：`<p class="ck-locator muted">原書：…</p>`
5. `<nav class="lc-pager">`：上一章／下一章（沿用 reader-chapter 的結構與 class：`a.lc-prev`、`a.lc-next`，內含 `<span class="muted">上一章</span><span>N　標題</span>`）

## cscs-concepts.html（`<article class="lib-series ck-concepts">`，載入 `css/library.css`、`css/cscs.css`）
- `<header class="ls-hero">`：kicker「肌力與體能訓練精要」、`<h1 class="ls-title">概念索引</h1>`、`<p class="ls-lead">` 說明「22 條概念，每條橫跨多章；照概念讀，可以把散在各章的同一件事串起來。」（數字實算）
- 依 `_concepts.yaml` 的 group 分組（`<h2>` group 名，依各 group 內最小 order 排序），組內依 order 排：每個概念 `<section class="ck-concept" id="<key>">`：`<h3>` zh、`<p class="muted">` desc、`<p class="ck-concept-count">` 「出現在 X 章、Y 條」；再列出所有帶此概念的 item，**依章分組**：`<p class="ck-concept-ch">第 N 章 · 章名</p>` 後接 `<ul class="ck-concept-items">`，每條 `<li><a href="<章節頁>#<item id>">q</a></li>`
- 概念超過 12 條 item 時，第 13 條以後收進 `<details><summary>看全部 Y 條</summary>`

## cscs.js
- `.ck-quiz-toggle` 按下：切換 `aria-pressed`，在 `article.ck-chapter` 加／移除 class `is-quiz`
- `is-quiz` 狀態下：點 `.ck-q` 切換該 item 的 class `is-revealed`
- 網址帶 `#<item id>` 時，若該 item 在 `is-quiz` 狀態也要加 `is-revealed`
- 無 JS 時一切可讀（答案預設顯示）

## cscs.css（只用 tokens 變數；不准卡片框、陰影、圓角 > 4px）
- `.ck-topic > h2`：上方 2px `--ink` 規則線、`padding-top: var(--s2)`、`margin-top: var(--s6)`
- `.ck-item`：上方 1px `--rule`、上下 `var(--s3)`；`scroll-margin-top: var(--s3)`
- `.ck-q`：襯線 `--fs-l` 粗體
- `.ck-a`：襯線、行高 1.8
- `.ck-numbers b`：`--series` 色
- `.ck-terms`、`.ck-concepts`、`.ck-related`、`.ck-locator`：`--fs-s`；concepts 連結用 `--series` 色文字、不加框
- `.is-quiz .ck-item:not(.is-revealed) .ck-a, .is-quiz .ck-item:not(.is-revealed) .ck-numbers, .is-quiz .ck-item:not(.is-revealed) .ck-detail { display: none; }`；`.is-quiz .ck-q { cursor: pointer; }`
- `.ck-quiz-toggle`：`min-height: var(--tap)`、1px `--rule` 邊框、背景 `--paper`；`[aria-pressed="true"]` 背景 `--series`、字 `--paper`
- 概念頁：`.ck-concept` 上方 1px `--rule`；`.ck-concept-ch` 用 `--series` 色 `--fs-s` 粗體
