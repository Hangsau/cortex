## hugo.next.toml
- `baseURL = "https://hangsau.github.io/cortex/next/"`，`languageCode = "zh-Hant"`，`title = "Cortex"`，`publishDir = "public/next"`
- `disableKinds = ["taxonomy", "term", "RSS", "sitemap", "robotsTXT"]`
- `[module]` 的 mounts 只掛這些（不掛舊的 content／layouts／static／assets）：
  - `next/content` → `content`
  - `next/layouts` → `layouts`
  - `next/assets` → `assets`
  - `data` → `data`
  - `next/data` → `data`
- `[markup.goldmark.renderer] unsafe = true`（資料含少量 HTML）

## 版型（Hugo ≥0.146 新樣板系統：`layouts/baseof.html`、`layouts/home.html`、`layouts/page.html`、`layouts/section.html`、`layouts/_partials/`）
`baseof.html` 結構（照寫，class 名不可改，shell.css 依賴它們）：
```html
<!doctype html>
<html lang="zh-Hant">
<head>{{ partial "head.html" . }}</head>
<body class="{{ if or (eq .Section "vortex") (hasPrefix .RelPermalink (relURL "vortex/")) }}series-vortex{{ else }}series-vortex{{ end }}">
{{ partial "site-head.html" . }}
<main id="main">{{ block "main" . }}{{ end }}</main>
<footer class="site-foot">Cortex · 新版預覽</footer>
</body>
</html>
```
（目前只有 Vortex，一律 `series-vortex`；保留條件式結構供之後擴充。）

`head.html`：meta charset、viewport（`width=device-width, initial-scale=1`）、`<title>`（頁標題 · Cortex；首頁只寫 Cortex）、`<meta name="description">`（有 `.Description` 才輸出）、依序載入 `css/tokens.css`、`css/shell.css`（`resources.Get` + `fingerprint`），再依 `.Params.css`（字串清單）載入額外 CSS。不載入任何網路字型。

`site-head.html`：
```html
<header class="site-head">
  <a class="site-name" href="{{ relURL "" }}">Cortex</a>
  {{ if 頁面在 vortex 底下 }}<a class="series-name" href="{{ relURL "vortex/" }}">Vortex 水感</a>{{ end }}
  <nav class="crumbs" aria-label="路徑">…</nav>
</header>
```
crumbs：從 `.Ancestors`（反轉成由上而下）列出，排除站首頁與 vortex 首頁本身，每層一個連結，最後加目前頁標題（不連結），用 ` › ` 分隔。首頁與 vortex 首頁不輸出 crumbs。

`page.html`、`section.html`：通用備用版型，輸出 `<div class="page"><h1>{{ .Title }}</h1><div class="read">{{ .Content }}</div></div>`。

`home.html`（站首頁）：`.page` 內 h1「Cortex」，一段 `.read` 文字「個人知識庫的新版預覽。目前先完成 Vortex 水感知識庫；其他系列（CSCS、肌動學、基礎生物力學、大腦喜歡這樣學、UST、氣質）會在下一階段接入。」，再一個連結「進入 Vortex 水感知識庫 →」到 `vortex/`。

`next/content/_index.md`：front matter `title: Cortex`。
`next/content/vortex/_index.md`：front matter `title: Vortex 水感`、`params: { role: home }`、`description: 以水感知為核心的游泳知識庫：泳式動作、練習、常見誤區與背後機制。`

## deploy.yml
在既有 Build 步驟**之後**、Upload 步驟**之前**加一個步驟，失敗不可影響正式站：
```yaml
      - name: Build next preview
        run: |
          pip install pyyaml || true
          python3 tools/build_vortex_links.py || echo "links build failed"
          hugo --minify --config hugo.next.toml || echo "next preview build failed"
```
其他內容一字不改。
