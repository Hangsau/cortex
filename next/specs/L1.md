# L1：書房（Vortex 以外所有系列）的統一資料索引

## 產出檔（只准建立這一個）
- `tools/build_library.py`
執行後產生 `next/data/library.json`（Hugo 內以 `hugo.Data.library` 讀取）。驗收腳本已寫好，不必寫測試。

## 規格
Python 3，只依賴 PyYAML 與標準函式庫；repo 根目錄由 `Path(__file__).resolve().parents[1]` 推得。
輸出 UTF-8 JSON（`ensure_ascii=False`，`separators=(",",":")`）。執行結束印一行摘要（各系列 chapters／entries 數）。

**YAML 陷阱**：`data/temperament/traits.yaml` 的 `no: 1` 會被 PyYAML 解析成布林 `False` 當 key。讀 yaml 一律用自訂 loader，把 `yes/no/on/off` 當字串：
```python
class StrLoader(yaml.SafeLoader): pass
for ch in "yYnNoO":
    StrLoader.yaml_implicit_resolvers[ch] = [r for r in StrLoader.yaml_implicit_resolvers.get(ch, []) if r[0] != "tag:yaml.org,2002:bool"]
```
（讀進來後 `no` 的值是字串 "1"，轉 int。）

讀 Markdown front matter：檔案開頭 `---` 到下一個 `---` 之間的 YAML。

### JSON 結構
```json
{
  "series": [
    {
      "id": "kinesiology",
      "group": "strength",
      "group_name": "肌力與動作",
      "title": "…", "title_en": "…", "author": "…", "edition": "…",
      "lead": "一段導言",
      "path": "library/kinesiology/",
      "chapters_label": "章",
      "chapters": [ {"n": 1, "id": "neumann.ch01", "title": "…", "desc": "…", "path": "library/kinesiology/ch01/", "part": "…或空字串"} ],
      "entries_label": "",
      "entries": [ {"id": "…", "title": "…", "desc": "…", "path": "…", "group": "…", "group_name": "…"} ],
      "tools": [ {"title": "…", "desc": "…", "path": "…"} ]
    }
  ]
}
```
所有 path 相對站根、以 `/` 結尾、不含 baseURL。沒有的欄位給空字串或空陣列，不可省略 key。

### 六個系列（依此順序）
1. **kinesiology**（group strength「肌力與動作」）：`data/reading/books.json` 的 `neumann`：title、title_en、author、edition、`description` 當 lead 的第一句；lead 用 `content/library/kinesiology/_index.md` front matter 的 `description`。chapters 取 books.json 的 chapters：n=number、id、title、path、part=group 欄位的中文（對照見下）；desc 讀 `content/library/kinesiology/chNN/index.md`（NN 兩位數）front matter 的 `description`。chapters_label「章」。tools：`{"title":"跨書主題對照","desc":"同一個主題在兩本書怎麼講","path":"library/kinesiology/topics/"}`。
2. **basic-biomechanics**（strength）：同上，用 books.json 的 `nordin`、`content/library/basic-biomechanics/`。tools 同樣放「跨書主題對照」但 path 用 `library/basic-biomechanics/topics/`（若該檔不存在就不放）。
   part 中文對照：先讀 books.json 裡是否有 group 名稱表；沒有就直接用 group 原值。
3. **cscs**（strength）：title「肌力與體能訓練精要」、title_en「Essentials of Strength Training and Conditioning」、author「Haff, Triplett」、edition「第 4 版」；lead：「NSCA 肌力與體能專家（CSCS）認證的指定教材。24 章拆成 1,557 條知識單位，每條都有答案、深度說明與原書出處。」（數字從資料實算後填入）。path `library/essentials-of-strength-training/`。chapters：`data/cscs/ch01.yaml`…`ch24.yaml`，n=章號、id=`chNN`、title=yaml 的 title、desc=前三個 topic 的 title 用「、」串接（超過三個加「等」）、path `library/essentials-of-strength-training/chNN/`。tools：`{"title":"概念索引","desc":"22 條概念，跨章節照概念讀","path":"library/essentials-of-strength-training/concepts/"}`（數字實算）。
4. **mnfl**（group learning「學習與教學」）：title「大腦喜歡這樣學」、title_en「A Mind for Numbers」、author「芭芭拉・歐克莉（Barbara Oakley）」、edition「」；lead：「給學習者的方法書。20 個讓學習更有效的技法，依五個主題分組，每個技法都寫了原理與做法。」（數字實算）。path `library/mind-for-numbers/`。chapters 為空陣列；entries_label「技法」；entries：`data/mnfl/techniques.yaml` 每個 theme 的每個 technique：id、title=name、desc=essence（去掉 `**`，截 60 字）、path `library/mind-for-numbers/<technique id>/`、group=theme id、group_name=theme name。
5. **ust**（learning）：title「大腦喜歡這樣學・強效教學版」、title_en「Uncommon Sense Teaching」、author「Barbara Oakley、Beth Rogowsky、Terrence Sejnowski」、edition「」；lead：「給教學者的版本。10 章教學手冊與 18 個課堂策略，從大腦怎麼學推到課堂怎麼教。」（數字實算）。path `library/uncommon-sense-teaching/`。chapters：`data/ust/chapters.yaml`，n=num、id=`ust.chNN`、title、desc=subtitle（沒有就用 claim 截 60 字）、path `library/uncommon-sense-teaching/chNN/`（NN 兩位數）。entries_label「策略」；entries：`data/ust/strategies.yaml` 的 strategies：id、title=name、desc=essence 截 60 字、path `library/uncommon-sense-teaching/strategies/<id>/`、group=category、group_name=categories 對應 name。
6. **temperament**（group temperament「氣質」）：title「兒童九種氣質」、title_en「Temperament · Goodness of Fit」、author「Thomas & Chess 等」、edition「」；lead：「氣質沒有好壞，決定孩子發展的是氣質與環境要求之間的適配度。九個維度、三型傾向、五種現代框架，以及怎麼配合。」path `temperament/`。chapters（文章）依序：
   `{"n":1,"id":"temp.traits","title":"九個維度","desc":"描述孩子的九把尺","path":"temperament/traits/"}`、
   `{"n":2,"id":"temp.types","title":"三型傾向","desc":"好養型、慢熱型、磨難型，以及無法歸類的多數","path":"temperament/types/"}`、
   `{"n":3,"id":"temp.frameworks","title":"現代框架","desc":"五種當代氣質框架怎麼看同一件事","path":"temperament/frameworks/"}`、
   `{"n":4,"id":"temp.fit","title":"適配度應用","desc":"不同氣質需要什麼樣的環境配合","path":"temperament/fit/"}`、
   `{"n":5,"id":"temp.critique","title":"批判與邊界","desc":"這套理論能說什麼、不能說什麼","path":"temperament/critique/"}`。
   entries_label「維度」；entries：`data/temperament/traits.yaml` 的 dimensions：id=key、title=name_zh、desc=definition、path `temperament/traits/<key>/`、group「traits」、group_name「九個維度」。
