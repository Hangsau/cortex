# V7：水感級別頁加入 L 級指標

## 產出檔（只准修改這一個）
- `next/layouts/_partials/vortex/unit.html`（W5 建立的知識點頁；**只在 type 為 `level` 的分支加一個區塊**，其他分支一字不改）

## 資料
`data/vortex/l-indicators.yaml`：`levels[]`（key、name_zh、perception、quant_ref）、`indicators[]`（id、stroke、level、aspect、indicator、framework_state、evidence[]、note、quant_ref）。
level 單位（`hugo.Data.vortex_links.units.<id>`，type=level）的 record 有 `stroke`（如 `free`）與 `level`（如 `L3`）；以此找 indicators 中 stroke 與 level 都相同者（indicators 的 stroke 值域可能不同，先用 python 印出來比對，再在版型裡做對應）。

## 規格
在 level 頁「是什麼」區塊之後加：
```html
<section class="layer layer-indicators"><h2>這一級看得到的指標</h2> … </section>
```
每個指標：`<h3>` aspect、`<p class="read">` indicator、framework_state（`muted`）、evidence 清單（每項 text＋certainty，來源顯示 source 字串）。沒有對應指標就整塊不輸出。
